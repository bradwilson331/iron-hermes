## Decision: Per-Model Wildcards Not in Schema

Per RESEARCH §Open Question 3, entries like `providers.ollama.models.<model>.extra_request_options.num_ctx` are intentionally NOT enumerated in the static schema Vec. The current `hermes config` validator uses exact key-string matching — adding per-model entries would require either:
- Enumerating every known model name (not scalable), or
- Extending the validator to support prefix-pattern matching (architectural change, out of scope for Phase 36.15)

Operators set per-model overrides directly in YAML. The schema covers only the six provider-level canonical keys. A future enhancement could extend the validator with a prefix-match rule for `providers.<name>.models.<model>.extra_request_options.<key>`, but that is beyond Phase 36.15 scope.
