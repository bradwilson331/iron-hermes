The `--skills` arg is structurally redundant — Plan 01 (this plan) removes the emitter side.

Per CONTEXT.md the executor must add `HERMES_KANBAN_TASK_SKILLS=<JSON-array-of-slugs>` to `build_kanban_worker_env` output (only when `task.skills` is `Some(non_empty)`), so the receiver-side wiring (a follow-up minor concern, not in this phase) can consume it later via the same env pattern as `HERMES_KANBAN_TASK`. The phase scope is closed at the emitter switch; receiver-side consumption of extras is out of scope for 36.3.7.0 per scope_fences (no new features).
