## Q2 Risk Gate (validation-critical)

Per RESEARCH.md Q2: `tower_http::trace::DefaultOnRequest` and `DefaultOnResponse` default to `Level::DEBUG`, NOT `Level::INFO`. Without explicit `.level(Level::INFO)` setters, the locked per-layer filter `tower_http::trace=info` would silently drop every HTTP event — `web-access.log` would exist but be empty.

**Status: STRUCTURALLY CLOSED.**

**Evidence (grep on merged HEAD):**

```
$ grep -c -E "DefaultOnRequest::new\(\)\.level\(Level::INFO\)|DefaultOnResponse::new\(\)\.level\(Level::INFO\)" crates/iron_hermes_ui/src/main.rs
2
```

Both setters present at `main.rs:50` (`on_request`) and `main.rs:51` (`on_response`). Inline comment block at `main.rs:44-48` cites RESEARCH.md Q2 / Pitfall 1 so future refactors don't strip the explicit setters without understanding why.

UAT script Gate 3 (`scripts/uat/phase-36.17-web-logging.sh:241-256`) is the behavioral net — it asserts `web-access.log` contains the literal `tower_http::trace` target string, with a failure message that explicitly cites RESEARCH.md Q2 as the recovery affordance.

**The Q2 failure mode is no longer reachable without an active code change that removes the explicit setters.**
