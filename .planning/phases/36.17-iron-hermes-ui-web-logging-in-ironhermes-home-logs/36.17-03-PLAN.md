       The `.on_request(DefaultOnRequest::new().level(Level::INFO))` and `.on_response(DefaultOnResponse::new().level(Level::INFO))` calls are MANDATORY. The locked per-layer filter `tower_http::trace=info` (set in Plan 02) will silently drop every HTTP event without them, because `DefaultOnRequest`/`DefaultOnResponse` default to `Level::DEBUG` per docs.rs/tower-http/0.6.8 (RESEARCH.md Q2). This is the single most important line of code in the entire phase.
