## Risk Flag (Validation-Critical, from RESEARCH.md Q2)

`TraceLayer::new_for_http()` defaults to **DEBUG** for both `on_request` and `on_response`. Without explicit `.on_request(DefaultOnRequest::new().level(Level::INFO))` and `.on_response(DefaultOnResponse::new().level(Level::INFO))`, the per-layer filter `tower_http::trace=info` will silently drop every HTTP event and `web-access.log` will exist but be empty.

**The UAT script MUST assert non-empty `web-access.log` content (`grep -q "tower_http::trace"`), not just file existence.** This is the single highest-leverage check in the entire validation strategy.
