<objective>
Create the Phase 36.17 UAT script `scripts/uat/phase-36.17-web-logging.sh` (and its parent directory). The script:
1. Sets `IRONHERMES_HOME` to a fresh tmp dir.
2. Starts `iron_hermes_ui --features server` in the background, waits for it to bind.
3. Sends one HTTP request via `curl` to trigger `TraceLayer`.
4. Gracefully shuts the server down with `SIGTERM` so both `WorkerGuard`s flush.
5. Asserts BOTH log files exist, BOTH have INFO content, NEITHER has ANSI, AND `web-access.log` carries the `tower_http::trace` target string.

Purpose: This is the single behavioral verification that catches the Q2 risk (TraceLayer default level is DEBUG → empty access log). A file-exists check alone would pass even with the bug. Content assertion is the gate.

Output: One new executable bash file under a newly-created `scripts/uat/` directory; running the script on the freshly-merged Wave 1+2 changes exits 0.

This plan is `autonomous: false` because the executor must start a real server process listening on a real port and curl it — that requires a free port and a clean exit on the host machine, which is not safely automatable across all dev environments. The script ITSELF runs unattended; what's not automatable is "the executor running this script during execute-plan must have a free port available", which is a human/environment precondition. The verification of the script is hands-on.
</objective>
