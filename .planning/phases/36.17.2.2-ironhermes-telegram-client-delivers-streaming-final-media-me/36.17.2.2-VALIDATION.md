## Sampling Rate

- **After every task commit:** Run `cargo test -p ironhermes-gateway <module>` for the file just touched (e.g. `markdown_v2` or `media_tag`).
- **After every plan wave:** Run `cargo test -p ironhermes-gateway` (full gateway crate including new integration test).
- **Before `/gsd:verify-work`:** `cargo test --workspace` green AND live UAT operator `approved` reply per D-20 / 36.17.2 D-22 protocol.
- **Max feedback latency:** unit ~1s, gateway suite ~30s, workspace ~120s.
