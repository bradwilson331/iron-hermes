**Core `feed()` loop — partial-prefix buffering** (streaming_scrubber.rs:56-122):
```rust
pub fn feed(&mut self, text: &str) -> String {
    if text.is_empty() {
        return String::new();
    }

    // Prepend any previously held partial-tag tail.
    let mut buf = if self.buf.is_empty() {
        text.to_owned()
    } else {
        let mut b = std::mem::take(&mut self.buf);
        b.push_str(text);
        b
    };

    let mut out = String::new();

    loop {
        if buf.is_empty() { break; }

        if self.in_span {
            match Self::find_ascii_ci(&buf, CLOSE_TAG) {
                None => {
                    let held = Self::max_partial_suffix(&buf, CLOSE_TAG);
                    if held > 0 {
                        let split = buf.len() - held;
                        self.buf = buf[split..].to_owned();
                    }
                    return out;       // inside span — drop everything
                }
                Some(idx) => {
                    buf = buf[idx + CLOSE_TAG.len()..].to_owned();
                    self.in_span = false;
                }
            }
        } else {
            match Self::find_ascii_ci(&buf, OPEN_TAG) {
                None => {
                    let held = Self::max_partial_suffix(&buf, OPEN_TAG);
                    if held > 0 {
                        let split = buf.len() - held;
                        out.push_str(&buf[..split]);
                        self.buf = buf[split..].to_owned();
                    } else {
                        out.push_str(&buf);
                    }
                    return out;
                }
                Some(idx) => {
                    if idx > 0 { out.push_str(&buf[..idx]); }
                    buf = buf[idx + OPEN_TAG.len()..].to_owned();
                    self.in_span = true;
                }
            }
        }
    }
    out
}
```

**`flush_tail` semantics** (streaming_scrubber.rs:130-138 — `flush`):
```rust
pub fn flush(&mut self) -> String {
    if self.in_span {
        self.buf.clear();
        self.in_span = false;
        return String::new();      // discard unterminated span (safer to truncate)
    }
    let tail = std::mem::take(&mut self.buf);
    tail
}
```

**ASCII-case-insensitive byte search — MUST port exactly (CR-01 regression mitigation)** (streaming_scrubber.rs:148-173):
```rust
fn find_ascii_ci(haystack: &str, needle: &str) -> Option<usize> {
    let h = haystack.as_bytes();
    let n = needle.as_bytes();
    if n.is_empty() || h.len() < n.len() { return None; }
    (0..=h.len() - n.len()).find(|&i| h[i..i + n.len()].eq_ignore_ascii_case(n))
}

fn max_partial_suffix(buf: &str, tag: &str) -> usize {
    let b = buf.as_bytes();
    let t = tag.as_bytes();
    let max_check = b.len().min(t.len() - 1);
    for i in (1..=max_check).rev() {
        let suffix_start = b.len() - i;
        if b[suffix_start..].eq_ignore_ascii_case(&t[..i]) {
            return i;
        }
    }
    0
}
```

**Adaptation notes (analog → MediaTagExtractor):**
- Tags become `OPEN_TAG = "<MEDIA:"`, no symmetric close tag — close on first `>` after open. Single tag grammar `<MEDIA:\s*([^>]+)>` per D-06.
- Replace `in_span: bool` with `in_tag: bool`. Add `tag_body: String` accumulator (the URL/path being captured) — scrubber discards span content, extractor MUST capture it.
