# Phase 36.3.7.2 Plan 02: No-Top-Level-Schema-Combinators Receiver Lock Summary

Installed the bilateral receiver-end regression lock for BUG-IRONHERMES-TOOLS-SCHEMA-COMPAT-03: a new integration test that walks every tool registered via `ToolRegistry::register_defaults()` and asserts none emit a top-level `oneOf`, `allOf`, or `anyOf` in their `input_schema`.

- **Line count:** 56 (minimum required: 40)
- **Registration path used:** `ToolRegistry::register_defaults()` (not the hardcoded-list fallback)
