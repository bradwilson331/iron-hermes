<objective>
Build the goal-loop wrapper — the only substantive new file in this phase. Per RESEARCH Finding 8 + Pitfall 5, this is a CLI-side helper that wraps `AgentLoop::run()` in a budget-bounded loop with judge invocation, CAS-gated per-turn counter bumps, subkind-tagged event emission, and a Drop-guard that guarantees the synthetic `kanban_block` fires on budget exhaustion even if the loop body panics.

The fn signature (per RESEARCH Finding 8 sketch):
```
pub async fn run_goal_loop_if_enabled(
    agent_loop: &mut AgentLoop,
    initial_messages: Vec<ChatMessage>,
    task_id: &str,
    run_id: &str,
    claim_lock: &str,
    judge_fn: &JudgeFn,
    store: &KanbanStore,
) -> anyhow::Result<()>
```

Five behavioral paths:

| Path | Trigger | Outcome | Drop guard? |
|------|---------|---------|-------------|
| Non-goal passthrough | `HERMES_KANBAN_GOAL_MODE` unset | single `agent_loop.run(initial_messages).await?`; no event emission; no budget tracking | n/a (no goal state) |
| Judge-met exit | judge returns `Met` | `done=true`; loop returns Ok(()) cleanly | not fired |
| Self-termination | `store.get_task(task_id).status` ∈ {Done, Blocked} after a turn | `done=true`; loop returns Ok(()) | not fired |
| Budget exhaustion | turn counter hits `goal_max_turns` without met or self-term | append `goal_budget_exhausted` event + synthetic `kanban_block(reason="goal_max_turns exhausted; needs human review")` BEFORE return | fires (or explicit equivalent — see RAII section) |
| Two-strike judge error | `judge_fn` returns Err twice consecutively | append two `judge_error` events; synthetic `kanban_block(reason="judge unavailable")` | not fired (block already emitted) |

The wrapper is invoked from `crates/ironhermes-cli/src/main.rs:281-323` (worker-mode detection neighborhood). Per RESEARCH Finding 1 there is no separate `worker_loop.rs`; the existing `inject_kanban_guidance_if_worker` happens at main.rs:281-288 and the kanban tool registration at main.rs:299-323; the wrapper invocation slots in alongside this — calling into `agent_loop.run()` THROUGH `run_goal_loop_if_enabled` instead of directly.

    Step 4 — Implement `run_goal_loop_if_enabled`:
    ```
    pub async fn run_goal_loop_if_enabled(
        agent_loop: &mut AgentLoop,
        initial_messages: Vec<ChatMessage>,
        task_id: &str,
        run_id: &str,
        claim_lock: &str,
        judge_fn: &JudgeFn,
        store: &KanbanStore,
    ) -> Result<()> {
        if std::env::var("HERMES_KANBAN_GOAL_MODE").is_err() {
            // Non-goal passthrough: existing manual worker path preserved byte-for-byte.
            agent_loop.run(initial_messages).await?;
            return Ok(());
        }
        let max_turns: u32 = std::env::var("HERMES_KANBAN_GOAL_MAX_TURNS")
            .ok()
            .and_then(|s| s.parse().ok())
            .unwrap_or(20);

        let task = store.get_task(task_id)
            .context("goal_loop: fetch task for title/body")?;
        let title = task.title.clone();
        let body = task.body.clone().unwrap_or_default();

        let mut sentinel = BudgetSentinel {
            store, task_id, run_id, goal_max_turns: max_turns,
            goal_turns_used: 0, done: false,
        };
        let mut messages = initial_messages;
        let mut consecutive_judge_errors: u32 = 0;

        for turn in 0..max_turns {
            // (a) one agent invocation — shared &mut agent_loop preserves session.
            let result = agent_loop.run(messages.clone()).await
                .context(format!("goal_loop turn {}: AgentLoop::run", turn))?;

            // (b) CAS-gated counter bump.
            let bumped = store.bump_goal_turn_counter(task_id, claim_lock)
                .context("goal_loop: bump_goal_turn_counter")?;
            if !bumped {
                // Stale claim → reclaim happened mid-loop. Emit a judge_error
                // advisory (uses the same subkind because the loop is dying for
                // the same reason: out-of-band state change).
                let _ = store.append_event(task_id, Some(run_id), KanbanEventKind::Edited,
                    Some(&serde_json::json!({"subkind": GOAL_SUBKIND_JUDGE_ERROR, "error": "claim_expired", "turn": turn + 1})));
                sentinel.done = true;
                return Ok(());
            }
            sentinel.goal_turns_used = turn + 1;
            let _ = store.append_event(task_id, Some(run_id), KanbanEventKind::Edited,
                Some(&serde_json::json!({"subkind": GOAL_SUBKIND_TURN_ADVANCED, "turn": turn + 1})));

            // (d) self-termination check.
            let fresh = store.get_task(task_id)?;
            if matches!(fresh.status, /* Done */ _ if status_is_terminal(&fresh.status)) {
                sentinel.done = true;
                return Ok(());
            }

            // (e) judge invocation.
            let req = JudgeRequest {
                task_id: task_id.to_string(),
                title: title.clone(),
                body: body.clone(),
                worker_turn_output: extract_final_assistant_text(&result),
                turn: turn + 1,
            };
            match judge_fn(req).await {
                Ok(JudgeOutput { verdict: JudgeVerdict::Met, reason }) => {
                    let _ = store.append_event(task_id, Some(run_id), KanbanEventKind::Edited,
                        Some(&serde_json::json!({
                            "subkind": GOAL_SUBKIND_JUDGE_VERDICT,
                            "verdict": "met", "reason": reason, "turn": turn + 1,
                        })));
                    sentinel.done = true;
                    return Ok(());
                }
                Ok(JudgeOutput { verdict: JudgeVerdict::NotMet, reason }) => {
                    let _ = store.append_event(task_id, Some(run_id), KanbanEventKind::Edited,
                        Some(&serde_json::json!({
                            "subkind": GOAL_SUBKIND_JUDGE_VERDICT,
                            "verdict": "not_met", "reason": reason.clone(), "turn": turn + 1,
                        })));
                    consecutive_judge_errors = 0;
                    messages.push(ChatMessage::user(format!(
                        "Judge verdict: not met. Reason: {}\nContinue working toward the acceptance criteria.",
                        reason,
                    )));
                }
                Err(e) => {
                    let snippet: String = format!("{:#}", e).chars().take(200).collect();
                    let _ = store.append_event(task_id, Some(run_id), KanbanEventKind::Edited,
                        Some(&serde_json::json!({
                            "subkind": GOAL_SUBKIND_JUDGE_ERROR, "error": snippet, "turn": turn + 1,
                        })));
                    consecutive_judge_errors += 1;
                    if consecutive_judge_errors >= 2 {
                        synthetic_kanban_block(store, task_id, run_id, "judge unavailable")?;
                        sentinel.done = true;
                        return Ok(());
                    }
                    // Else: continue to next turn; judge is treated as not-met by the next iteration's
                    // synthetic user message? No — per D-04 the loop just treats the turn as elapsed
                    // and proceeds; the worker LLM does not see judge errors as text.
                }
            }
        }
        // Loop exits naturally: budget exhausted. Sentinel Drop emits block.
        // Explicit equivalent (Rust style — explicit is clearer than implicit Drop):
        // (the Drop will fire AGAIN; suppress the double-emit via the `done` flag).
        Ok(())
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker LLM output → judge prompt | LLM-generated worker_turn_output crosses into the judge's user message — untrusted; the judge system prompt is static. |
| Task body (acceptance criteria) → judge prompt | User/orchestrator-supplied body content reaches the judge; could carry prompt injection. |
| Worker LLM → kanban_block / kanban_complete tool calls (self-termination) | The wrapper detects self-termination by reading store state; the worker can self-terminate any time. |
| Drop-time DB writes (BudgetSentinel) | Panics or partial state at Drop must not produce orphaned `running` cards or leak provider responses. |
| Stale claim_lock mid-loop | Reclaim+respawn can invalidate the worker's authority mid-turn; CAS gate (Plan 02) is the load-bearing defense. |
