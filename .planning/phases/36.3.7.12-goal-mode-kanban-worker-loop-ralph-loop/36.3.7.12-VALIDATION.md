## Nyquist Compliance

- **Dimension 1 (Unit coverage):** every new pure fn / SQL helper gets a test in the same crate's `tests/` dir.
- **Dimension 2 (Integration):** new cross-crate flows (goal loop calls into kanban store, store emits events, dispatcher claims goal_mode cards) covered by integration tests in `crates/ironhermes-kanban/tests/` and `crates/ironhermes-cli/tests/`.
- **Dimension 3 (Bilateral regression):** every BUG fixed during execution ships producer + consumer tests in the same commit set (LEARNINGS 2026-05-30).
- **Dimension 4 (Frozen-surface assertion):** add a test that asserts no new `KanbanEventKind` variants land (variant count == existing count). Mirrors Phase 36.3.7.6 idiom.
- **Dimension 5 (CAS gate):** per-turn writes assert run_id via `cas::assert_run_id_tx` — covered by an explicit "reclaimed worker cannot bump counter" test.
- **Dimension 6 (Manual UAT):** the four manual-only verifications above must sign off before phase close.
- **Dimension 7 (Workspace gate):** `cargo build/test/clippy --workspace --features iron_hermes_ui/server -- -D warnings` exit 0.
- **Dimension 8 (Threat coverage):** every threat in PLAN.md's `<threat_model>` block has a corresponding mitigation test.
