# Phase 36.17.3 Plan 04: TUI Queue Production Wiring — Fields, Drain Hook, Status Pill — Summary

**One-liner:** Wired the App-owned `MessageQueue<SessionKey>` plumbing into the
`tui_rata` REPL — added `queue`/`queue_key`/`queue_paused` fields, a guarded
`maybe_drain_queue` method hooked into `StreamEvent::Finished` (and defensively
`Error`), and the hide-when-zero `Queue: N` status-bar pill reading live per
render pass — without touching `commands.rs` or the test surfaces (deferred to
Plans 05 / 03 / 06).

## What Shipped

### Task 1 — App + AppDeps + test_deps + event_loop wiring (commit `49ce5f0b`)

`crates/ironhermes-cli/src/tui_rata/app.rs`:
- Added imports: `MessageQueue` (core), `SessionKey` (core), `Platform` (core types).
- `AppDeps` gained `pub queue: Arc<dyn MessageQueue<SessionKey>>` and
  `pub queue_paused: Arc<AtomicBool>` immediately after `fast_enabled` (D-03,
  D-06 amended). Per D-03 `queue_key` is NOT in AppDeps — it is a TUI constant
  derived in `App::new`.
- `App` struct gained `queue`, `queue_key: SessionKey`, `queue_paused` after
  `fast_enabled`.
- `App::new(deps)` forwards `queue: deps.queue`, `queue_paused: deps.queue_paused`,
  and computes `queue_key: SessionKey::new(Platform::Local, "local").with_user("local")`
  (D-03 fixed TUI key — the relocated `SessionKey::new` signature from
  Plan 01 takes `(Platform, impl Into<String>)` then `.with_user(impl Into<String>)`).
- `test_deps()` (test-support gated) populates the new AppDeps fields with
  `Arc::new(SessionQueue::new()) as Arc<dyn MessageQueue<SessionKey>>` and
  `Arc::new(AtomicBool::new(false))`.

`crates/ironhermes-cli/src/tui_rata/event_loop.rs::build_app_deps`:
- Production construction of `let queue: Arc<dyn MessageQueue<SessionKey>> =
  Arc::new(SessionQueue::new())` and the paused-toggle `AtomicBool`, then
  forwarded into the AppDeps struct literal alongside `fast_enabled`.

### Task 2 — `maybe_drain_queue` + Finished/Error hooks (commit `2d6a0c92`)

`crates/ironhermes-cli/src/tui_rata/app.rs`:
- New private method `fn maybe_drain_queue(&mut self)` placed immediately after
  `commit_assistant_buffer` (~line 800). Body:
  1. **Guard 1 (D-06):** `if self.queue_paused.load(Ordering::Relaxed) { return; }`
  2. **Guard 2 (T-04 / RESEARCH Pitfall 3):** `if self.pending_tx.is_some() { return; }`
  3. `if let Some(text) = self.queue.pop(&self.queue_key)` — mirrors `submit()`:
     - `self.history.push(user_message(text));`
     - allocate `tokio::sync::mpsc::unbounded_channel::<StreamEvent>()`
     - set `pending_rx`, `pending_tx`
     - `cancel_child = Some(self.cancel_parent.child_token())`
     - `auto_follow = true`
     - `assistant_buffer = None`
- `StreamEvent::Finished` arm ends with `self.maybe_drain_queue();` (D-04 hybrid
  auto-drain).
- `StreamEvent::Error(e)` arm sets `self.queue_paused.store(true, Ordering::Relaxed)`
  then calls `self.maybe_drain_queue()` (Resolution 4 — paused guard short-
  circuits the pop; symmetric belt-and-suspenders).
- `StreamEvent::Cancelled` arm intentionally does NOT call `maybe_drain_queue`,
  with an inline comment citing RESEARCH Pitfall 1 (/stop clears queue before
  firing cancel; draining here would be a regression).

### Task 3 — Status pill + live ui.rs wiring (commit `25965e77`)

`crates/ironhermes-cli/src/tui_rata/status_line.rs`:
- `StatusLineState` gained `pub queue_depth: usize` and `pub queue_paused: bool`
  after `session_total_tokens`. `Default` populates both as `0`/`false`.
- `build_pills()` adds the queue pill AFTER the `session_total_tokens` pill
  and BEFORE the `let hint = ...` block:
  - `state.queue_depth > 0 && state.queue_paused` → `Queue: {N} (paused)`
  - `state.queue_depth > 0 && !state.queue_paused` → `Queue: {N}`
  - `state.queue_depth == 0` → no pill pushed (hide-when-zero matches the
    `agents`/cost/token discipline).

`crates/ironhermes-cli/src/tui_rata/ui.rs::render_status`:
- Clones `app.status` per render pass; overrides
  `state.queue_depth = app.queue.len(&app.queue_key)` and
  `state.queue_paused = app.queue_paused.load(Ordering::Relaxed)` LIVE.
- No cached StatusLineState fields — RESEARCH Pitfall 5 (off-by-one-tick
  staleness) avoided by reading per frame.

## Deviations from Plan

None — plan executed exactly as written.

The plan's Task 2 (c) noted that on `StreamEvent::Error` the simpler form is
to skip `maybe_drain_queue` entirely and only set `paused=true`. The shipped
implementation kept the symmetric belt-and-suspenders form (set paused +
call drain — the paused guard short-circuits the pop). This is explicitly
permitted by the plan ("Pick the simpler form if equivalent in behaviour;
document choice in task summary."). The symmetric form was chosen because
it preserves future flexibility if a later phase wants to swap the error
policy (e.g., auto-unpause-on-transient-error) without needing to revisit
the arm wiring.

## T-04 Mitigation Trail

The plan's threat model registers **T-04 (Denial of Service: `App::maybe_drain_queue`
reentry)** with `disposition: mitigate`. The mitigation lives in **Guard 2** of
`maybe_drain_queue`:

```rust
if self.pending_tx.is_some() {
    return;
}
```

This guard is verifiable at compile-time by the acceptance grep
`awk '/fn maybe_drain_queue/,/^    \}/' | grep -c 'pending_tx.is_some'`
returning ≥ 1. The check passed (returned 1).

## How It Wires Together

```
event_loop.rs::build_app_deps
    └─ creates Arc<SessionQueue> + Arc<AtomicBool> for pause
        └─ flows into AppDeps { queue, queue_paused, ... }
            └─ App::new(deps) forwards both + derives queue_key
                └─ App now owns queue / queue_key / queue_paused

handle_stream_event::Finished
    └─ self.maybe_drain_queue()
        ├─ Guard 1: paused?           → return (D-06)
        ├─ Guard 2: turn in flight?   → return (T-04)
        └─ pop + mirror submit() setup → event_loop spawns next turn

handle_stream_event::Error
    └─ queue_paused.store(true)        (Resolution 4)
    └─ self.maybe_drain_queue()        (no-op via paused guard)

handle_stream_event::Cancelled
    └─ NO drain call                   (Pitfall 1)

ui.rs::render_status (every frame)
    └─ clone app.status
    └─ override state.queue_depth = app.queue.len(&queue_key)   (live)
    └─ override state.queue_paused = app.queue_paused.load(...)  (live)
    └─ render_status_line_ratatui(&state)
        └─ build_pills pushes "Queue: N" / "Queue: N (paused)" / nothing
```
