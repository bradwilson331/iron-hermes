## Known Stubs

The three new test files (`tui_queue_drain.rs`, `tui_queue_controls.rs`,
`status_line_queue_pill.rs`) ship intentionally trivial bodies under
`#[ignore = "Plan 06 fills body"]`. This is **by design** for Wave 2 — the
file structure, imports, and helper functions are the deliverable; the
assertion bodies are Plan 06's responsibility (per the plan objective and
the PATTERNS.md §7 harness specification). The `#[ignore]` attribute means
`cargo test` skips these tests by default, so they cannot mask a regression.
