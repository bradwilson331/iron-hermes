**How `MessageQueue` mirrors it** — place in `crates/ironhermes-core/src/queue.rs`:
```rust
use std::hash::Hash;

/// Shared FIFO queue abstraction (Phase 36.17.3, D-01).
/// Surface = FIFO data ops only. Each consumer owns its own drain orchestration.
pub trait MessageQueue<K: Hash + Eq + Clone>: Send + Sync {
    /// Push message text onto the per-key FIFO.
    /// Returns Err if the queue is at capacity (cap=128 matches gateway constant).
    fn try_push(&self, key: &K, message: String) -> Result<(), QueueError>;

    /// Pop the oldest message for the given key, or None if empty.
    fn pop(&self, key: &K) -> Option<String>;

    /// Current depth for the given key, or 0 if no queue allocated.
    fn len(&self, key: &K) -> usize;

    /// Drop all queued messages for the given key (idempotent).
    fn clear(&self, key: &K);
}
```

**`QueueError` re-export:** Move `QueueError` from `session_queue.rs` to `queue.rs` (or define a new one in core). The gateway's existing type (`session_queue.rs` lines 52-62):
```rust

pub enum QueueError {
    #[error("Queue at capacity ({max}) for session {session_key}")]

}
```

/// Called from handle_stream_event on StreamEvent::Finished (D-04).
/// Guards: not paused, no turn already in-flight (Pitfall 3 in RESEARCH.md).
fn maybe_drain_queue(&mut self) {

    if self.queue_paused.load(Ordering::Relaxed) {

        self.pending_tx = Some(tx);

        self.auto_follow = true;
        self.assistant_buffer = None;
    }
}
