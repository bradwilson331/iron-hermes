## Decisions Made

- **Free-fn helpers for paused-flag tests, not AppState construction** — followed the existing `phase_36_1_02_state_tests` module pattern (running_agents tests use free-fn helpers, not full AppState init). The free-fn `get_or_create_paused` mirrors the method body verbatim, so the algorithm is unit-tested without paying the async AgentRuntime + StateStore init cost. The method-level contract is enforced separately by the `cargo check --features server` gate (which exercises the field types and method signature at compile time) and the acceptance-criteria greps.
- **Added stronger `Arc::ptr_eq` idempotency assertion** to `paused_flag_persists_across_lookups` than the original `flag_persists_across_lookups` test had. The plan's `<behavior>` explicitly required pointer-equal idempotency, and the original running_agents triplet only asserted value-equal (via the second handle observing the first handle's store). Carries the invariant strictly going forward; does not weaken any existing assertion.
- **Did not touch `.omc/project-memory.json`** which had a pre-existing un-staged modification (not part of this task's diff).
