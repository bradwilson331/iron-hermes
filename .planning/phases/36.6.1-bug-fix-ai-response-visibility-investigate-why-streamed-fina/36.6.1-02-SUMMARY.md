### Task 2: D-03 Integration Test (ui.rs)

Full body of `auto_scroll_lands_at_true_bottom_after_stream_finished`:

```rust
#[test]
fn auto_scroll_lands_at_true_bottom_after_stream_finished() {
    use crate::tui_rata::app::App;
    use crate::tui_rata::event_loop::compute_transcript_area;

    // 25 lines ~50 chars each → ~25 wrapped rows; viewport = 17 (19-row block minus 2 borders)
    let long_body: &'static str = Box::leak(
        (1..=25)
            .map(|i| format!("Line {:02}: some assistant content here.", i))
            .collect::<Vec<_>>()
            .join("\n")
            .into_boxed_str(),
    );
    let mut app = App::new_test_with_messages(vec![("assistant", long_body)]);

    let size = ratatui::prelude::Size { width: 80, height: 24 };
    let transcript_area = compute_transcript_area(size);

    // Simulate StreamEvent::Finished: scroll_to_bottom sets auto_follow=true, transcript_scroll=0
    app.scroll_to_bottom();
    // reconcile_scroll sets transcript_scroll = transcript_max_scroll(area) when auto_follow
    app.reconcile_scroll(transcript_area);

    let max = app.transcript_max_scroll(transcript_area);
    assert!(max > 0, "test setup: expected max_scroll > 0 ...");
    assert_eq!(app.transcript_scroll, max,
        "auto-scroll must land at true bottom: scroll={}, max={}", ...);

    // Visual: render and check last content row is non-blank
    // transcript_area.height = 19; last content row = y = 19-2 = 17
    let backend = TestBackend::new(80, 24);
    let mut terminal = Terminal::new(backend).unwrap();
    terminal.draw(|f| ui(f, &app)).unwrap();
    let buf = terminal.backend().buffer();
    let last_visible_row = (transcript_area.height - 2) as u16; // = 17
    let last_row_non_blank = (1u16..78u16).any(|col| {
        buf.cell((col, last_visible_row)).map(|c| c.symbol() != " ").unwrap_or(false)
    });
    assert!(last_row_non_blank, "last visible row (row {}) must be non-blank ...", last_visible_row);
}
```

### Layout Geometry Discovery

For an 80x24 terminal with layout `[Min(5), Length(1), Length(1), Length(3)]`:

| Chunk | Height | y-range in buffer |
|-------|--------|-------------------|
| transcript block | 19 | 0..18 |
| knight-rider | 1 | 19 |
| status | 1 | 20 |
| input | 3 | 21..23 |

Content rows in transcript: y=1..17 (border at y=0, y=18). Last content row = y=17. RESEARCH §6 Pitfall 4 describes "rows 1..22" which assumes the transcript fills all 24 rows — it does not.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] flush_word closure double-counted extra row for oversized words at row-start**
- **Found during:** Task 2 — `wrapped_overflows_one_row` test failed: `word_wrapped_line_count("helloworld!", 10)` returned 3, expected 2
- **Issue:** When a single word wider than `width` starts at the beginning of a row (`current_row_width == 0`), the old code emitted `rows += 1` (wrap to new row) AND then `word_rows - 1` (character-wrap rows). But since we were already at row-start, the wrap-to-new-row step was spurious — the word should character-split starting from the current row, not from a new one.
- **Fix:** Added `if *current_row_width > 0 || *pending_ws_width > 0` guard before `rows += 1`. Only wrap to a new row if we're not already at a row boundary.
- **Files modified:** `crates/ironhermes-cli/src/tui_rata/app.rs`
- **Commit:** `c8e86871`

**2. [Rule 1 - Bug] Visual assertion used wrong row index (y=22 instead of y=17)**
- **Found during:** Task 2 — test failed on visual assertion: "last visible row (row 22) must be non-blank"
- **Issue:** RESEARCH §6 Pitfall 4 states "rows 1..22 (inner) for a 24-row terminal" — but this assumes the transcript block is 24 rows tall. The actual transcript chunk is 19 rows (24 - 1 - 1 - 3 = 19), so the last content row is y=17, not y=22.
- **Fix:** Changed `let last_visible_row = 22u16` to `let last_visible_row = (transcript_area.height - 2) as u16` (computed dynamically from the actual area).
- **Files modified:** `crates/ironhermes-cli/src/tui_rata/ui.rs`
- **Commit:** `c8e86871`

**3. [Rule 1 - Bug] 5 insta snapshot tests failed due to stale snapshots**
- **Found during:** Task 2 full suite run
- **Issue:** `word_wrapped_line_count` now correctly returns `max_scroll > 0` for content that previously returned 0. This causes the scrollbar (▲, █, ▼) to appear in rendered frames that previously had no scrollbar. Insta snapshots captured the incorrect (no-scrollbar) rendering.
- **Fix:** Accepted the 5 new snapshots (`snap_error_banner`, `snap_in_flight_streaming_partial_delta`, `snap_scroll_active_indicator`, `snap_tool_call_activity_row`, `snap_two_message_conversation`) — the new snapshots are correct.
- **Files modified:** `crates/ironhermes-cli/tests/snapshots/*.snap` (5 files)
- **Commit:** `c8e86871`

**4. [Rule 3 - Blocking] Worktree branch missing Plan 01 commits**
- **Found during:** Task 2 initial test run — test failed because `word_wrapped_line_count` wasn't present (app.rs had old `wrapped_line_count`)
- **Issue:** This worktree branch forked from develop before Plan 01's commits (`6fb6c229`, `4b4fcad0`, `ad8068d0`) were merged. The D-03 test requires the fixed formula from Plan 01 to be meaningful.
- **Fix:** Merged `develop` into the worktree branch (`git merge develop --no-edit`). Merge commit `1ecce7c2`.
- **Commit:** `1ecce7c2`
