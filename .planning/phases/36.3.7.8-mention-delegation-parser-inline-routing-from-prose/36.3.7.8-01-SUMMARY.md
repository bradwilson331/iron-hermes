# Phase 36.3.7.8 Plan 01: @mention Parser + Resolver Foundation Summary

**One-liner:** Pure-function `parse_mentions` with CommonMark fence-state machine + `resolve_mention` three-stage pipeline with configurable fallback policies and constant-time self-mention reject.

## What Was Built

### Task 1 — Parser module (`mention/mod.rs` + `mention/parser.rs` + `lib.rs`)

`parse_mentions(body: &str) -> Vec<MentionSpan>` uses a redact-then-scan strategy:

1. `redact_non_prose(body)` walks the body byte-by-byte through a `ScanState` machine, replacing all non-prose bytes (fenced code blocks, inline code spans, HTML comments) with ASCII spaces while preserving the total byte count.
2. The static `HANDLE_RE` (`@([A-Za-z0-9][A-Za-z0-9-]*)`) scans the redacted string and collects `MentionSpan { handle, byte_offset }` values pointing into the original body.

The invariant `redact_non_prose(body).len() == body.len()` is enforced by a `debug_assert_eq!` and verified by the `redact_non_prose_preserves_byte_length` test.

### Task 2 — Resolver module (`mention/resolver.rs`)

`resolve_mention(handle: &str, ctx: &ResolverCtx<'_>) -> Resolution` implements the five-step pipeline per D-03/D-04:

1. Lowercase the handle (Landmine 5 — `validate_profile_name` is lowercase-only).
2. Validate via `ironhermes_core::profile::validate_profile_name` → `Skipped(Malformed)` on failure.
3. Self-mention quick reject (constant-time string compare against `ctx.parent_assignee`) → `Skipped(SelfReference)`. Takes precedence over UnknownHandle when both conditions apply.
4. Existence gate: `ctx.known_assignees.contains(&name)` → `Resolved(name)`.
5. Fallback policy: `Skip` → `Skipped(UnknownHandle)`; `Pending` → `Fallback("pending", UnknownHandle)`; `Error` → `Skipped(UnknownHandle)` with caller-contract doc comment.

`pub const MAX_MENTION_CHAIN_DEPTH: usize = 4` exported for Plan 02 store layer.

6 unit tests ship in `#[cfg(test)] mod tests`:

- `self_mention_returns_skipped_self_reference`
