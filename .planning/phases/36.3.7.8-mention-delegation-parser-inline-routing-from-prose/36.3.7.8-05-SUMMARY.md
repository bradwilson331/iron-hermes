## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Handle names with underscores caused test failures**
- **Found during:** Task 1 (first test run)
- **Issue:** Initial test handles like `@real_mention`, `@unknown_handle` used underscores. The parser regex `@([A-Za-z0-9][A-Za-z0-9-]*)` doesn't match underscores, so mentions were never parsed. Similarly, `validate_profile_name` rejects underscores causing `Skipped(Malformed)` instead of `Skipped(UnknownHandle)`.
- **Fix:** Renamed all test handles to alphanumeric-hyphen names: `ghostbot`, `realauthor`, `visibleauthor`, `hiddenbot`, `inlinecode`
- **Files modified:** `crates/ironhermes-kanban/tests/tools_smoke.rs`
- **Verification:** All 17 mention tests pass after fix
- **Committed in:** `e48e8855` (Task 1 commit)
