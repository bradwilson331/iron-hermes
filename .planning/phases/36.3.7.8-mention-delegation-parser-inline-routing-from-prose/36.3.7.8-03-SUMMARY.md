## What Was Built

### `crates/ironhermes-kanban/src/tools/mention.rs` (451 LOC)

Complete `Tool` trait implementation for `kanban_mention`:

- **Struct**: `KanbanMentionTool { store: Arc<TokioMutex<KanbanStore>>, explicit_enable: bool }`
- **Constructor**: `KanbanMentionTool::new(store, explicit_enable)`
- **`reject()` helper**: copied verbatim from `tools/swarm.rs:56-64`
- **`is_available()`**: `std::env::var("HERMES_KANBAN_TASK").is_ok() || self.explicit_enable`
- **Schema**: `task_id` (string, optional), `body_override` (string, optional), `fallback_policy` (enum `"skip"|"pending"|"error"`, default `"skip"`), `idempotency_key` (string, optional); `additionalProperties: false`
- **11-step execute flow**:
  1. Resolve `task_id` from args or `$HERMES_KANBAN_TASK`; `reject("invalid_task_id")` if neither
  2. Parse `fallback_policy` string (default `"skip"`); `reject("invalid_policy")` on parse error
  3. Read optional `idempotency_key`
  4. Acquire store lock; fetch parent via `store.get_task(&task_id)`; `reject("task_not_found")` on error
  5. Determine body: `body_override` arg OR `parent.body.unwrap_or_default()`
  6. `parse_mentions(&body)` — pure function, O(n) string scan
  7. Build `known_assignees` HashSet via inline `SELECT DISTINCT assignee FROM tasks WHERE assignee IS NOT NULL AND assignee != ''`
  8. For each span: `resolve_mention(&span.handle, &ctx)` → `children` or `skipped` vecs; `reject("unknown_handle")` if `policy=Error` and `Skipped(UnknownHandle)`
  9. Build `MentionPlan { parent_id, children, idempotency_key, workspace, skills, tenant, created_by }`
  10. `store.create_mention_children(plan)` — maps error keywords to rejection slugs
  11. Return `{ task_id, mentions_parsed, children_created: [{child_id, assignee, handle}], skipped: [{handle, reason}] }`
- **Rejection slugs**: `invalid_task_id`, `task_not_found`, `invalid_policy`, `unknown_handle`, `invalid_assignee`, `mention_cycle`, `store_error`
- **3 in-file smoke tests** (all pass under `--test-threads=1`):
  - `tool_name_and_toolset_are_kanban_mention`
  - `tool_schema_lists_fallback_policy_enum`
  - `tool_is_available_respects_env_and_explicit_enable`
