## Summary

Phase 36.3.7.8 delivers the 11th kanban LLM tool, its CLI parity verb, the gateway slash-deferral entry, and the store-layer atomic transaction primitive — all behind a pure-function parser + three-stage resolver. The codebase shows:

- Pure parser (`mention/parser.rs`) implementing CommonMark §6.5 / §6.6 fence-state machine via redact-then-scan with byte-offset preservation invariant (`redact_non_prose(body).len() == body.len()`).
- Three-stage resolver (`mention/resolver.rs`) doing lowercase → `validate_profile_name` → self-mention quick reject → existence gate → fallback policy with documented hard-error contract for `FallbackPolicy::Error`.
- Atomic store primitive (`store.rs::create_mention_children`) opening `BEGIN IMMEDIATE`, with inside-tx idempotency replay (WR-01 carry-over from 36.3.7.7), `WITH RECURSIVE ancestors` walk bounded at `MAX_MENTION_CHAIN_DEPTH=4`, inlined 3-INSERT sequence (tasks/task_links/task_events), RAII rollback on per-child failure. `create_task` signature byte-preserved (INV-36.3.7).
- LLM tool (`tools/mention.rs`) implementing `Tool` trait, wired into `register_kanban_tools` as the 11th `registry.register(...)` call. Docstring bumped 10→11.
- CLI verb (`KanbanCommands::Mention`) + `cmd_mention` async handler calling `store.create_mention_children` directly (per Landmine 7 — CLI does NOT go through tool registry).
- Gateway routing: `"mention"` appended to `DEFERRED_KANBAN_SUBVERBS`.
- Docs reconciliation: §14 "10 LLM tools" → "11 LLM tools", §200 table grows by one row, §741 deferral marker replaced with `*Shipped in Phase 36.3.7.8.*`.
- Tests: 18 receiver tests in `tools_smoke.rs` (≥ 15 required), 4 CLI parity tests (≥ 4 required), 1 deferred-subverb membership test, 17 in-module unit tests (parser+resolver+tool smoke). All 41 passing, zero failures.
