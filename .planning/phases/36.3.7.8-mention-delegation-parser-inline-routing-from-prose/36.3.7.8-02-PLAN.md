ANCESTOR-WALK SQL (REQ-10 layer 2 — inverted from 36.3.7.6 descendants CTE per PATTERNS.md):

  -- Walk PARENTS of the parent task up to MAX_MENTION_CHAIN_DEPTH hops.
  -- Reject the child if `resolved_assignee` matches any ancestor task's assignee.
  WITH RECURSIVE ancestors(id, depth) AS (
      SELECT parent_id, 1 FROM task_links WHERE child_id = ?1
      UNION
      SELECT tl.parent_id, a.depth + 1
        FROM task_links tl
        JOIN ancestors a ON tl.child_id = a.id
       WHERE a.depth < ?2
  )
  SELECT 1 FROM tasks t
   WHERE t.id IN (SELECT id FROM ancestors)
     AND t.assignee = ?3
   LIMIT 1

  Bind order: (?1 = plan.parent_id, ?2 = MAX_MENTION_CHAIN_DEPTH as i64, ?3 = resolved_assignee).
  If query returns any row → child is a cycle → REJECT (rollback whole batch per REQ-11).
