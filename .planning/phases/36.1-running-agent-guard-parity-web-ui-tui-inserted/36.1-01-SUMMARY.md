# Phase 36.1 Plan 01: Create ironhermes-core::commands::running_agent Module Summary

Extracted `RunningAgentGuard`, `is_bypass`, and `AGENT_RUNNING_REJECT_MSG` from `ironhermes-gateway/src/handler.rs` into a new canonical module `ironhermes-core::commands::running_agent`, with re-export through the gateway's `lib.rs` so all existing call sites and integration tests continue working without modification.

## What Was Built

**Task 1 — Create `ironhermes-core::commands::running_agent` module:**

Created `crates/ironhermes-core/src/commands/running_agent.rs` with verbatim copy of the three items from gateway handler.rs:62-103:
- `pub const AGENT_RUNNING_REJECT_MSG` — D-02 locked rejection string
- `pub struct RunningAgentGuard(Arc<AtomicBool>)` — RAII guard; both store sites use `Ordering::SeqCst` (Pitfall 3)
- `pub fn is_bypass(name: &str) -> bool` — bypass list `stop | new | status | queue` with TODO comment preserved

Six unit tests in `#[cfg(test)] mod tests`:
1. `is_bypass_locked_list` — verifies exact bypass membership and case-sensitivity
2. `guard_sets_flag_on_construction` — flag is true while guard is in scope
3. `guard_clears_flag_on_drop` — flag is false after guard dropped
4. `guard_clears_flag_on_panic` — Drop fires on panic exit via `catch_unwind`
5. `reject_msg_constant_value` — byte-for-byte D-02 string assertion
6. `is_bypass_keeps_todo_for_approve_deny` — approve/deny NOT in bypass list

Appended `pub mod running_agent;` to `commands/mod.rs` and added `pub use commands::running_agent::{RunningAgentGuard, is_bypass, AGENT_RUNNING_REJECT_MSG};` to `src/lib.rs`.

**Task 2 — Update gateway to import from core:**

In `handler.rs`:
- Removed `AtomicBool` from the atomic import (no longer needed)
- Added `use ironhermes_core::commands::running_agent::{RunningAgentGuard, is_bypass, AGENT_RUNNING_REJECT_MSG};`
- Deleted the 43-line local guard definition block (lines 62-104)

In `lib.rs`:
- Changed `pub use handler::RunningAgentGuard;` to `pub use ironhermes_core::commands::running_agent::RunningAgentGuard;`
