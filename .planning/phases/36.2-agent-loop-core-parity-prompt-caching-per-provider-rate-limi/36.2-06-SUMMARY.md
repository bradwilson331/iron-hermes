# Phase 36.2 Plan 06: RateLimitTracker — Summary

`RateLimitTracker` ships in `ironhermes-agent` as a pure-observability,
broadcast-emitting per-provider tracker keyed by `(provider, api_key_hash,
model)`. Anthropic's `anthropic-ratelimit-*` headers (RFC 3339 reset) and
OpenRouter/Nous's `x-ratelimit-*` headers (float-seconds reset) parse into
the same `TrackerState`; reactive 429s feed the same broadcast event surface.
Plan 07 has the full primitive set it needs to wire the tracker into the
post-LLM-call site.

## Objective Recap

Land the per-provider in-memory `RateLimitTracker` module in
`ironhermes-agent` (D-RL-04: not in `ironhermes-core` — would muddle the
gateway user rate-limiter at `config.rs:812`). Three-axis key
`(provider, api_key_hash, model)` per D-RL-02; structured
`RateLimitEvent`s on `tokio::sync::broadcast::channel(64)`; provider-aware
header parsing (RESEARCH.md correction #1); reactive 429 fallback (D-RL-01);
SHA-256-truncated-16-bytes API-key hashing via `sha2 0.10.9` (RESEARCH.md
correction #5); pure observability — no `fallback_providers` /
`classify_llm_error` references (D-RL-03); cleartext keys cannot escape
(T-36.2-06-LEAK).

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| SHA-256-truncated-16-bytes via `sha2 0.10.9` (NOT blake3) | `blake3` is NOT in `Cargo.lock`; D-RL-02 "Claude's Discretion" permits SHA-256 substitution. The workspace already pins `sha2 = "0.10"` so adding `sha2 = { workspace = true }` to the agent crate is a one-line change with zero new external packages. | Zero supply-chain surface added; truncated 128-bit hash is well above birthday-collision risk for the <10 keys a single user holds. |
| Provider routing via plain `match provider` on `"anthropic"` vs `_` | Simplest possible dispatch — no Provider enum dep, no trait object indirection, no string-set matching. Anthropic is the only header-prefix outlier; everything else (OpenAI, OpenRouter, Nous, Cohere, etc.) speaks `x-ratelimit-*`. | One-line match block; Tests 3+4+5 lock the dispatch contract. |
| Manual `impl Debug for RateLimitTracker` (no derive) | T-36.2-06-LEAK requires that map contents cannot escape via the Debug surface. Derived `Debug` would print every `RateLimitKey` (including `provider` + `model` strings), every `TrackerState`. Manual impl restricts output to `entries: N`. | Test 13 + invariant 7 + invariant 4 jointly lock the bounded-Debug + no-cleartext-literal contract. |
| `compute_severity` short-circuits on `Critical` but allows `Warning` upgrade from any bucket | The 0%-remaining + near-reset case must yield Warning even if a *prior* bucket was Info — the < 10% branch's `severity != Critical` guard preserves this. | Tests 9/10/11 verify all three severity tiers. |
| `broadcast::channel(64)` buffer + `let _ = tx.send(…)` send pattern | Standard `tokio::broadcast` idiom — `send` returns `Err` when no subscribers OR when buffer overflow drops oldest; both are non-panic. AgentLoop (Plan 07) will be the only steady-state subscriber so 64 is generous. | Test 12 fires 100 events with dropped receiver and the test passes without panic. |
| Added `pub fn len() / is_empty()` accessors | Manual `Debug` impl needs the entry count — making the accessor public avoids re-locking inside `fmt::Debug::fmt` and matches the standard `len()/is_empty()` pair. | Rule 2 (Critical Functionality) — `Debug` rendering would otherwise require duplicating the lock-and-read code inline. |
| `chrono::DateTime::parse_from_rfc3339` for Anthropic reset; `f64::parse` for x-ratelimit reset | Anthropic returns ISO 8601 absolute timestamps; OpenRouter/Nous return seconds-from-now. Two parser paths required by RESEARCH correction #1. `chrono` was already a workspace dep — zero new dep added. | Test 3 + Test 4 verify both reset paths produce a `SystemTime` in the expected window. |

## Cross-Plan Invariants (for Plan 07 consumers)

For Plan 07 wiring, AgentLoop's post-call site MUST:

```rust
// On every successful LLM response:
tracker.record_headers(
    provider,
    key_hash,
    model,
    response.headers().iter().map(|(k, v)| (k.as_str(), v.to_str().unwrap_or(""))),
);

// Whenever classify_llm_error_typed returns ProviderError::RateLimited:
if let ProviderError::RateLimited { retry_after } = &typed_err {
    tracker.record_429(provider, key_hash, model, *retry_after);
}
```

The tracker MUST NOT be called from inside `fallback_providers` or
`classify_llm_error` — D-RL-03 separation of concerns. Static-grep
invariants #2 + #3 guard the tracker source; Plan 07 must run its own
invariants to guard the consumer side.
