# Phase 36.2 Plan 04: PricingRegistry + PricingCache Summary

Hand-curated USD pricing table + disk-cache overlay for ironhermes-core, mirroring Phase 21.3's ModelRegistry pattern. Ships the cost-calculation primitive (`compute_cost_micros`) and the resolution chain (`PricingRegistry::lookup`) that Plan 07 will call per-turn to populate the new `usage_events.cost_usd_micros` column.

## What Was Built

### 1. `crates/ironhermes-core/src/pricing.rs` (180 lines)

- **`PricingEntry`** — strong-typed record with 5 fields: `provider: String` and four `i64` micro-USD rates per million tokens (input, output, cache_read, cache_creation). Derives `Debug, Clone, PartialEq, Eq, Serialize, Deserialize`.
- **`PricingRegistry`** — holds `table: HashMap<String, PricingEntry>` (bootstrapped from `include_str!("pricing.toml")`) plus `cache: HashMap<String, PricingEntry>` (disk-cache overlay).
- **`PricingRegistry::lookup(model_id)`** — 4-step resolution chain mirroring `ModelRegistry::lookup`:
  1. Exact match in cache
  2. Exact match in static table
  3. Strip `provider/` prefix and retry cache, then table
  4. Return None
- **`PricingRegistry::lookup_or_zero(model_id)`** — emits `tracing::warn!(model_id, "unknown model pricing — cost will be $0")` and returns a zero-cost entry. Never panics.
- **`PricingRegistry::merge_cache(entries)`** — overlay used by Plan 09 after a successful `hermes pricing refresh`.
- **`PricingRegistry::all_models()`** — sorted union of static + cache for `hermes pricing list`.
- **`PricingRegistry::from_toml_str(s)`** — strict-shape deserializer. The internal `PricingFile` struct has exactly one field (`models`), so spoofed top-level keys like `[exploit_payload]` parse to an empty models map (threat T-36.2-04-PARSE mitigation). Downstream invariant recorded for Plan 09: `parsed.models.len() > 0` check before save.
- **`compute_cost_micros(entry, in_tok, out_tok, cache_read, cache_create) -> i64`** — Anthropic's three-input billable formula. Sums `(tokens × rate) / 1_000_000` across all four token types. All `i64` integer arithmetic — zero `f64` in code paths.

### 3. `crates/ironhermes-core/src/pricing_cache.rs` (130 lines)

Byte-for-byte structural port of `models_cache.rs:1-87`:

- **`PricingCacheEntry { pricing, fetched_at: DateTime<Utc> }`** — timestamped pricing record.
- **`PricingCache { entries: HashMap<String, PricingCacheEntry> }`** — JSON-serialized at `$HERMES_HOME/pricing-cache.json`.
- **`load()` / `load_from(path)`** — missing or corrupt files return `Self::default()`. Never panics.
- **`save()` / `save_to(path)`** — pretty-printed JSON, parent dir auto-created.
- **`into_pricing_map()`** — strips the `fetched_at` wrapper, returns the shape `PricingRegistry::merge_cache` wants.
- **`fetch_from_models_dev()`** — async stub that `anyhow::bail!`s with "not yet implemented (Plan 09)". The surface lives here so callers can `pub use` it now; Plan 09 fills in the body.
