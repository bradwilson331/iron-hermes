## Wave 0 Requirements

Existing Rust test infrastructure covers all four sub-systems' validation needs (cargo test framework already installed; per-crate `tests/` directories already exist). No new test framework setup required.

Per-sub-system wave-0 test scaffolds the planner should anticipate:
- [ ] `crates/ironhermes-agent/tests/provider_error_classification.rs` — port hermes-agent's `error_classifier.py` test cases verbatim (D-ERR-04 parity bar — 30+ documented test patterns per RESEARCH.md §Validation Architecture).
- [ ] `crates/ironhermes-agent/tests/rate_limit_tracker.rs` — header parsing matrix (Anthropic `anthropic-ratelimit-*` RFC3339 vs OpenRouter/Nous `x-ratelimit-*` floats), per-key/per-model isolation, 429-fallback when headers absent.
- [ ] `crates/ironhermes-agent/tests/prompt_cache_assertion.rs` — cached layer stability assertion (debug panic / release warn); system_and_3 breakpoint placement; cache-break trigger detection (model swap / memory edit / context-file edit).

- [ ] `crates/ironhermes-core/tests/pricing_resolution.rs` — disk-cache > static-table > fallback precedence; `hermes pricing refresh` offline/online behavior; micros-USD integer math (no float drift).
