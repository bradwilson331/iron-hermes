# Phase 36.2 Plan 09: hermes pricing list/refresh CLI + models.dev fetch implementation Summary

`hermes pricing list` (prints merged static-table + cache overlay) and `hermes pricing refresh [--force]` (fetches from models.dev, writes `$HERMES_HOME/pricing-cache.json`) ship as a working CLI subcommand. Plan 04's `fetch_from_models_dev` bail stub is replaced with the real reqwest GET + strict-typed JSON parser; an `f64→i64 micro-USD` conversion gate (`cost_field_to_micros`) contains the only float-touching code in the entire pricing subsystem.

## What Was Built

### 1. `crates/ironhermes-core/src/pricing_cache.rs` (Plan 04 stub → real implementation)

Replaced the 6-line Plan 04 bail stub with ~130 lines of production code:

- **`pub const MODELS_DEV_URL: &str = "https://models.dev/api.json"`** — compile-time hardcoded. Threat T-36.2-09-URL (refresh URL forgery / spoofing) mitigation: adversary cannot redirect refresh traffic via config tampering because the URL is not a config field.
- **`fetch_from_models_dev() -> Result<HashMap<String, PricingCacheEntry>>`** — production entry; delegates to `fetch_from_url(MODELS_DEV_URL)`.
- **`fetch_from_url(url) -> Result<...>`** — test-injection seam that wiremock-backed tests use to drive the parser end-to-end. 30-second timeout (`FETCH_TIMEOUT_SECS`) caps DoS surface (T-36.2-09-DOS).
- **`parse_models_dev_body(json: &Value) -> HashMap<String, PricingCacheEntry>`** — pure parser, walks `provider → models → cost → {input, output, cache_read, cache_write}`. Strict typed extraction (`as_object()` / `as_f64()` / `as_i64()` / `as_u64()`) — unknown shapes silently degrade to an empty map (T-36.2-09-PARSE). Skips rows with all-zero `(input, output)` pricing — defensive against incomplete upstream data.
- **`cost_field_to_micros(field: Option<&Value>) -> i64`** — **the one and only f64 boundary in the pricing subsystem.** Handles `f64`, `i64`, `u64`, `None`, `null`, and non-numeric values gracefully (always returns 0 on miss). After this function, all arithmetic downstream is integer `i64` micro-USD.

### 2. `crates/ironhermes-cli/src/pricing_cmd.rs` (new file, ~210 lines)

- **`pub enum PricingSubcommand { List, Refresh { force: bool } }`** — clap subcommand enum mirroring `models_cmd::ModelsSubcommand:14-23`.
- **`pub async fn handle_pricing_command(cmd: PricingSubcommand) -> Result<()>`** — top-level dispatcher.
- **`async fn cmd_list() -> Result<()>`** + **`pub fn cmd_list_to_string(path: &Path) -> String`** — merges `PricingRegistry::new()` (bundled pricing.toml) with `PricingCache::load_from(path)`, renders a 6-column table (`MODEL`, `PROVIDER`, `IN/1M`, `OUT/1M`, `CACHE_R/1M`, `CACHE_CRE/1M`). The `_to_string` variant is pure (no stdout) for tests.
- **`fn render_pricing_list(...) -> String`** + **`fn format_micros_as_dollars(micros: i64) -> String`** — pure rendering helpers (mirrors `models_cmd::render_model_list` precedent).
- **`async fn cmd_refresh(force: bool) -> Result<()>`** — calls `cmd_refresh_from_url_with_path` against `MODELS_DEV_URL`, distinguishes fetch-failed vs empty-rejected via the error string's `EMPTY-REJECTED:` prefix, exits with code **2** on fetch failure and code **3** on empty-without-force. PRESERVES the existing disk cache on either failure path (threat T-36.2-09-OVERWRITE — `PricingCache::save_to()` is the LAST operation and never runs on failure).
- **`pub async fn cmd_refresh_from_url_with_path(url, force, cache_path) -> Result<usize>`** — test-injection seam used by behaviors 6-8 + 10.

### Threat Model Mitigations Verified

| Threat | Status | Evidence |
|--------|--------|----------|
| T-36.2-09-URL (Spoofing — refresh URL forgery) | Mitigated | `pub const MODELS_DEV_URL` compile-time; not a config flag; not user-overridable; production `fetch_from_models_dev` always uses the const. The test seam `fetch_from_url(url)` is `pub` BUT consumed only by tests (verified by grep — no production code path passes a non-const URL). |
| T-36.2-09-PARSE (Tampering — spoofed body) | Mitigated | Strict typed extraction via `.as_object()` / `.as_f64()` / `.as_i64()` / `.as_u64()`; unknown JSON shapes degrade to empty `HashMap`; `--force` is the explicit user opt-in for an empty body; the parsed body never feeds `format!`/`eval`/templating. Tests #5 + #6 cover happy + empty paths; tests #7-8 cover the `--force` gate. |
| T-36.2-09-FORCE (Repudiation — `--force` enables silent overwrite) | Accepted | `--force` is documented in the clap `arg` help text (`pricing_cmd.rs:33`). Test #8 confirms the escape hatch works; the user's explicit `--force` is the audit trail. |
| T-36.2-09-DOS (DoS — large response → memory exhaustion) | Accepted | `reqwest::Client::timeout(30s)` caps fetch duration. Real models.dev payloads are <100KB; OOM-kill at adversarial sizes is acceptable for a single-shot CLI command. |
| T-36.2-09-OVERWRITE (Tampering — failed fetch corrupts cache) | Mitigated | `cmd_refresh_from_url_with_path` calls `cache.save_to(path)` as the LAST operation; on `fetch_from_url` error OR empty-without-force, the function returns `Err` BEFORE `save_to` runs. Tests #7 + #9 verify byte-identical preservation. |
| T-36.2-09-SC (Tampering — package install) | Mitigated | **Zero new external dependencies.** Uses `reqwest`, `serde_json`, `chrono`, `clap`, `colored` (already on `ironhermes-cli`), and `wiremock` (already a dev-dep).
