<objective>
Add the three cache-break detection trigger sites required by D-CACHE-03 and emit warnings through the existing PRMT-10/11 `pressure_warning.rs` channel (no new emitter). The three triggers match Anthropic's documented cache-invalidation rules:
1. **Model swap mid-session** — `/model X` while the session has at least one prior turn invalidates the cached prefix. Detected at the slash-command handler.
2. **Memory edit mid-session** — MEMORY.md / USER.md mutation after session start. Detected at the memory tool write site.
3. **Context file edit mid-session** — SOUL.md / AGENTS.md / CLAUDE.md mtime change during a session. Detected via mtime snapshot at session start + per-turn poll.

Each trigger emits one warning per occurrence (idempotent per event), using the exact message phrasing in D-CACHE-03. The warnings travel on the existing Phase 34b out-of-band channel (`AgentResult.context_warnings` / `pressure_warning.rs` emitter) — no new delivery code, no new channel, no `/cache` command (D-CACHE-03 push-only).

Purpose: Surface cache invalidation to users so they understand why a "free" subsequent turn just spent full prompt tokens. This is a pure UX safety net for the cost-accounting work in Plan 07.

Output: Three new `pub async fn warn_cache_break_*` methods on the PressureTracker (or equivalent owner of the PRMT-10/11 channel); detection hooks wired at the three trigger sites in `agent_loop.rs`; integration test that drives each trigger and asserts the warning text matches verbatim.
</objective>

```rust
impl PressureTracker {
    /// D-CACHE-03 trigger 1: /model X swap mid-session.
    /// Message text MUST match D-CACHE-03 phrasing for parity tests.
    pub async fn warn_cache_break_model_swap(
        &self,
        session_id: &str,
        old_model: &str,
        new_model: &str,
        hooks: Option<&HookRegistry>,
    ) {
        let msg = format!(
            "Switching from {old_model} to {new_model} will invalidate the cached prefix; \
             next turn pays full prompt tokens."
        );
        self.emit_warning(session_id, &msg, hooks).await;
    }

    /// D-CACHE-03 trigger 2: MEMORY.md / USER.md mutation after session start.
    pub async fn warn_cache_break_memory_edit(
        &self,
        session_id: &str,
        hooks: Option<&HookRegistry>,
    ) {
        let msg = "Memory edit will invalidate cache; new snapshot applies at next session start (PRMT-06).";
        self.emit_warning(session_id, msg, hooks).await;
    }

    /// D-CACHE-03 trigger 3: SOUL.md / AGENTS.md / CLAUDE.md mutation mid-session.
    pub async fn warn_cache_break_context_file_edit(
        &self,
        session_id: &str,
        hooks: Option<&HookRegistry>,
    ) {
        let msg = "Context file edit will invalidate cache for this session.";
        self.emit_warning(session_id, msg, hooks).await;
    }
}
```

`emit_warning` is the existing internal entry point inside `pressure_warning.rs` used by `check_and_maybe_emit` (lines 67-79 per PATTERNS.md). The three new methods call it directly with the precomposed string — no new dispatcher logic.

Detection hooks live in `agent_loop.rs` (or wherever the corresponding events are handled today):
- **Model swap detection**: at the `/model` slash-command handler (or wherever `self.model` is mutated mid-session). Capture `old_model` BEFORE the mutation, call `warn_cache_break_model_swap` AFTER the mutation iff `self.turn_count > 0` (or equivalent "session has prior turns" predicate).
- **Memory edit detection**: at the memory-tool write site (search for the function/method that performs MEMORY.md / USER.md mutation — likely in the memory-tool dispatch in `agent_loop.rs` or in a sibling memory module). Call `warn_cache_break_memory_edit` iff the write was non-trivial (added/replaced/removed a non-empty entry) AND `self.turn_count > 0`.
- **Context file edit detection**: snapshot the mtime of SOUL.md / AGENTS.md / CLAUDE.md at session start (already shipped by Phase 15 context-file work). At each turn start, re-poll the mtimes; if any has changed, call `warn_cache_break_context_file_edit`. Update the snapshot to suppress duplicate warnings on the next turn.
