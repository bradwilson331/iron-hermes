```rust
/// Returns true when the (provider, model) pair is an OpenRouter routing to a Claude model.
/// OpenRouter routes Claude models with provider IDs like "anthropic/claude-opus-4-7".
fn is_openrouter_claude(provider: &str, model: &str) -> bool {
    provider == "openrouter" && (
        model.starts_with("anthropic/claude")
            || model.starts_with("claude-")     // some OpenRouter routes drop the provider prefix
    )
}
```

The ChatCompletions arm builds an OpenAI-compat request. When `is_openrouter_claude(provider, model)` is true AND `prompt_caching.enabled` is true, attach cache_control to:
- The last system message content block (corresponds to the Anthropic system-block attachment in Plan 05).
- The last content block of each of the last 3 non-system messages (system_and_3 strategy).

OpenAI-compat content blocks for OpenRouter Claude routing accept the same `cache_control` field as Anthropic native (RESEARCH.md A1 assumption). The JSON envelope:
```json
{
  "role": "user",
  "content": [
    { "type": "text", "text": "...", "cache_control": { "type": "ephemeral", "ttl": "1h" } }
  ]
}
```

The Plan 05 `CacheControl` struct in `anthropic_client.rs` can be re-exported as `pub(crate)` and reused here, OR duplicated in `any_client.rs` to avoid cross-module coupling. Pick re-export.
