## What Was Built

### Task 1 — Fast-path branch in runner.rs

Inserted a ~46-line branch immediately after the whitelist + @mention filters and before the multimodal processing + `UQM::dispatch` call site at `runner.rs:~925-970`.

**Branch structure:**
- `if event.content.starts_with('/')` — D-24 strict prefix, no whitespace trim
- Captures `handler_cmd`, `adapter_cmd`, `sem_cmd`, `cancel_cmd`, `event_cmd` from existing dispatch-loop locals
- `tokio::spawn(async move { ... })` — detached, NOT added to `worker_join_set` (D-27)
- Inside spawn: `sem_cmd.acquire().await` first (T-36.17.2-06 — TG-06 per-chat concurrency bound preserved)
- Builds `crate::multimodal::ProcessedAttachments { text_prefix: None, image_data_uri: None }` (D-27 — commands are text-only)
- Calls `handler_cmd.handle_with_multimodal(&event_cmd, adapter_cmd, cancel_cmd.child_token(), processed).await`
- Logs handler errors at `error!` level (chat_id + error tagged)
- `drop(permit)` explicit before task exit
- `continue;` after spawn to skip multimodal + UQM.dispatch path for this event

**Position verified:** fast-path at byte offset 46527, `user_queue_dispatch.dispatch` at 50494 — fast-path precedes UQM by ~4KB.

**Security (T-36.17.2-07):** Branch is positionally AFTER both the whitelist check (lines 904-914) and the @mention check (lines 916-923). Unwhitelisted users' slash commands are `continue`d before reaching the fast-path.
