# Phase 37.1 Plan 01: Wave-0 Test Scaffolding Summary

**One-liner:** Three intentionally-red test scaffolds encoding the target behavior for the setup-script-not-working-on-macos fix (config drift, wizard coverage, installer verb dispatch).

## What Was Built

### Task 1 — Rust test scaffolds (config_parity.rs + wizard_coverage.rs)

**`crates/ironhermes-core/tests/config_parity.rs`** (REQ-37.1-02)

Three tests asserting that `cli-config.yaml.example` covers all 27 typed `Config` top-level sections. Uses a `load_example_yaml()` helper reading the file via `CARGO_MANIFEST_DIR`. Mirrors the style of `config_validate.rs`.

- `example_covers_all_typed_config_sections` — iterates `REQUIRED_SECTIONS: &[&str]` (27 keys), asserts each is a top-level YAML key with a named-section failure message
- `example_deserializes_to_config_without_errors` — serde round-trip to `Config`
- `kanban_key_present` — key-presence-only assertion (per Open Question #3)

**Red state:** Compiles cleanly (`--no-run` exit 0). Runtime FAILS on `custom_providers` (and 8 others) missing from the example file.

**`crates/ironhermes-core/tests/wizard_coverage.rs`** (REQ-37.1-04)

Three tests for two not-yet-existing wizard functions: `apply_kanban_section_answer` (all 17 KanbanConfig fields) and `write_defaults_if_absent` (idempotent + insert-when-missing).

**Red state:** FAILS TO COMPILE — `E0432: unresolved imports apply_kanban_section_answer, write_defaults_if_absent`. This is the expected Wave-0 red state.

### Task 2 — Bash harness (tests/installer_integration.sh)

Five test functions invoking `bash install.sh <verb>` under an isolated fake HOME:

| Function | REQ | What it asserts |
|----------|-----|-----------------|
| `verify_uninstall` | REQ-37.1-05 | binary removed; `~/.ironhermes` preserved |
| `verify_uninstall_purge` | REQ-37.1-05 | `~/.ironhermes` removed with `--purge` |
| `verify_update_additive` | REQ-37.1-06 | user `config.yaml` values byte-unchanged after `update` |
| `verify_hermes_agent_detection` | REQ-37.1-08 | "hermes-agent detected" in stdout; `~/.hermes/config.yaml` byte-unchanged |
| `verify_openclaw_detection` | — | "openclaw" notice in stdout when `~/.openclaw/` exists |

Flag dispatch: `--verify` runs harness self-check only (exits 0); `--clean` removes temp dirs; no-arg runs all tests.

**Red state:** `--verify` exits 0. Full no-arg run exits 1 — install.sh has no verb dispatch, so `bash install.sh uninstall` runs the default install path which does not remove the binary.
