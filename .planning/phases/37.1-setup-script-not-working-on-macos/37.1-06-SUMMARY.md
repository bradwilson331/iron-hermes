# Phase 37.1 Plan 06: Windows Installer (install verb only) Summary

**One-liner:** Minimal PowerShell installer downloads `ironhermes-windows-x86_64.tar.gz` from GitHub Releases, installs to `%LOCALAPPDATA%\Programs\ironhermes\`, and adds it to user PATH idempotently.

---

## What Was Built

### install.ps1

A new `install.ps1` at the repo root implementing the `install` verb only. Key behaviors:

1. **IRONHERMES_REPO validation** (`Test-RepoUrl`) — mirrors `install.sh::validate_repo_url`: accepts only `https://` or `http://192.168.` URLs; rejects shell/format metacharacters (`;`, `|`, `&`, `$`, backtick, spaces, `(`, `)`, `<`, `>`). Threat T-37.1-06-01 mitigated.

2. **Version resolution** — reads `$env:IRONHERMES_VERSION` or calls `https://api.github.com/repos/bradwilson331/iron-hermes/releases/latest` via `Invoke-RestMethod`.

3. **Download** — fetches `ironhermes-windows-x86_64.tar.gz` (the exact Plan-04 release artifact) from GitHub via `Invoke-WebRequest` into a fresh temp dir.

4. **Extraction** — uses `tar -xzf` (bsdtar, ships on Windows 10 1803+). Threat T-37.1-06-02 mitigated: extract to temp, copy only `ironhermes.exe`, clean up temp dir.

5. **Install** — copies `ironhermes.exe` to `%LOCALAPPDATA%\Programs\ironhermes\` (user-scoped, no admin). Threat T-37.1-06-03 mitigated.

6. **PATH** — appends install dir to user PATH via `[Environment]::SetEnvironmentVariable('Path', ..., 'User')`, idempotent (case-insensitive check against existing entries).

7. **Deferred lifecycle note** — script prints a `[WARN]` that `update / reinstall / uninstall` are not supported on Windows (D-12), and instructs users to re-run the script to update or manually delete to uninstall.

### README.md

Added a `### Windows (install only)` subsection within the `## Installation` section, between the existing installer subcommands block and Option 2 (build from source). Documents:
- Two invocation patterns (pipe from raw.githubusercontent.com; download-then-run)
- What the script does (downloads, extracts, installs, edits user PATH)
- `IRONHERMES_REPO` override example
