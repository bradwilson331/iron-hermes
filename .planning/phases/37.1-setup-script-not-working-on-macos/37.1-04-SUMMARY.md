## Task 1: Create .github/workflows/release.yml

**Status:** COMPLETE — committed at `01440041`

Created `.github/workflows/release.yml` with:

- Tag-only trigger: `on: push: tags: ["v*"]` — orthogonal to ci.yml's branch/PR triggers

  1. `macos-15` / `aarch64-apple-darwin` / `ironhermes-macos-aarch64`

### Windows Packaging Approach

Used a **separate Windows-only step** (`if: runner.os == 'Windows'`) that copies `target/release/ironhermes.exe` then tars it. This is cleaner than a cross-shell one-liner because:
- `target/release/ironhermes` does not exist on Windows (binary is `.exe`)
- Separate steps make CI logs easier to read
- `tar` is available on `windows-latest` (Git for Windows provides it)
