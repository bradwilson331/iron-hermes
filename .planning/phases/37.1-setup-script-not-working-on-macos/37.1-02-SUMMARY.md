# Phase 37.1 Plan 02: Unified Installer + Repo-Name Fix Summary

Unified the IronHermes setup scripts into one canonical cross-platform bash installer (`install.sh`) with `install|update|reinstall|uninstall` subcommands (default = install, curl-pipe friendly). Fixed the `ironhermes` → `iron-hermes` repo-name bug in both `install.sh` and `README.md`. Added validated `IRONHERMES_REPO` override, macOS quarantine strip, `cargo install --git` fallback, existing-install detection (IronHermes / hermes-agent / openclaw), and retired `setup-ironhermes.sh` + `install-gitea.sh`. Turned the Wave-0 `tests/installer_integration.sh` harness green (5/5 tests pass).

## Tasks

### Task 1: Add subcommand dispatch + verbs + repo-name fix + IRONHERMES_REPO validation + quarantine strip + cargo-git fallback to install.sh

**Commit:** `163158cc`
**Files:** `install.sh`

Changes made to `install.sh`:

1. **Constants fix:** `REPO_NAME="ironhermes"` → `REPO_NAME="iron-hermes"`. Added `IRONHERMES_REPO="${IRONHERMES_REPO:-https://github.com/${REPO_OWNER}/${REPO_NAME}}"`.

2. **Security — `validate_repo_url()` (T-37.1-02-01):** Accepts `https://` or `http://192.168.` (Gitea LAN); rejects shell metacharacters (`;`, `|`, `&`, `$`, backtick, spaces, `(`, `)`, `<`, `>`); called before every curl/cargo use of `IRONHERMES_REPO`.

3. **macOS quarantine strip (T-37.1-02-03):** `xattr -d com.apple.quarantine "$INSTALL_DIR/ironhermes" 2>/dev/null || true` added after `install -m 755` in `download_binary()`.

4. **`cargo_install()` fixed:** Dead `cargo install ironhermes` replaced with `cargo install --git "$IRONHERMES_REPO" ironhermes`.

5. **`detect_existing_install()`:** Sets `IRONHERMES_EXISTS` / `HERMES_AGENT_EXISTS` / `OPENCLAW_EXISTS`. IronHermes: checks `~/.ironhermes/config.yaml` or `.env`. hermes-agent: checks `~/.hermes/` dir or config.yaml, prints exact required string `Legacy hermes-agent detected at ~/.hermes/. IronHermes uses ~/.ironhermes/ — your existing hermes-agent data is untouched.`, NEVER reads/writes `~/.hermes/` (T-37.1-02-05). openclaw: existence-check only, prints forward-compat notice.

6. **`seed_templates()` extended with `mode` param** (install|update|reinstall): install/update guard `[ ! -f ]`; reinstall appends missing top-level sections as commented blocks (additive-merge). `chmod 600 .env` runs on install AND update (T-37.1-02-04).

7. **Verb functions added:** `cmd_install` (current main body + `detect_existing_install`), `cmd_update` (re-fetch binary + `seed_templates update` + re-chmod 600 .env), `cmd_reinstall` (force re-fetch + `scaffold_home` + `seed_templates reinstall`), `cmd_uninstall` (rm binary, strip PATH lines via marker, preserve/purge `~/.ironhermes/`).

8. **Subcommand dispatch:** `VERB="${1:-install}"` + `case` dispatch; `uninstall` passes remaining args (e.g. `--purge`) to `cmd_uninstall`; unknown verb → usage + exit 1. `set -euo pipefail` and `IS_INTERACTIVE` TTY guard preserved.

**Verification:** `bash -n install.sh` OK. `bash tests/installer_integration.sh` 5/5 PASS.
