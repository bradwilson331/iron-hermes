**Geometry is: DYNAMIC**

The wheel SVG geometry is driven by a single named constant `pub const N: usize = 10`
at `crates/iron_hermes_ui/src/components/hermes_app/wheel.rs:58`. All downstream
geometry (`STEP = 360.0 / N as f64` at line 60, every `for i in 0..N` loop at lines
440, 479, 499) derives from `N` reactively. Bumping `N` from `10` to `11` automatically
updates `STEP = 360.0 / 11.0 ≈ 32.727°` and all three render loops.
