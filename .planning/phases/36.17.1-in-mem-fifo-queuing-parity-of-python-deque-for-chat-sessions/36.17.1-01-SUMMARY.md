# Phase 36.17.1 Plan 01: SessionQueue Type + Parity Mirror Summary

**One-liner:** Per-session `VecDeque<MessageEvent>` FIFO with 128-cap + 96-soft-warn, plus a `#[cfg(test)]` proptest-driven equivalence proof against Python's two-layer `pending_slot + overflow` layout — zero runtime cost.

## What Shipped

A new `crates/ironhermes-gateway/src/session_queue.rs` module containing:

1. **Production type** — `SessionQueue` wraps `Mutex<HashMap<SessionKey, VecDeque<MessageEvent>>>` and exposes the sync API `try_push`, `pop`, `len`, `is_empty`, `clear`, `retain`. Each method's rustdoc cites the equivalent Python helper from `gateway/run.py`.
2. **Error type** — `QueueError::CapacityReached { session_key: String, max: usize }` is the sole variant; named-field shape mirrors `HermesError::ContextOverflow`.
3. **Public constants** — `MAX_QUEUE_DEPTH = 128` (hard cap, D-09) and `WARN_QUEUE_DEPTH = 96` (soft-warn, D-11). Both `pub const` so adapter layers and `/queue` UX can quote the numbers.
4. **Unit suite (9 tests)** — `test_fifo_order`, `test_cap_at_128`, `test_soft_warn_at_96`, `test_clear_removes_all`, `test_retain_predicate`, `test_session_isolation`, `test_empty_pop_returns_none`, `test_clear_idempotent`, `test_session_key_full_triple_used` (T-36.17.1-02 mitigation).
5. **`#[cfg(test)] mod parity`** — `SessionFifoQueue` trait + `SplitSlotQueue` Python-layout mirror + `Op` alphabet + 1024-case `proptest_equivalence` + 300-op push-only `proptest_cap_invariant` + `split_slot_smoke` + `split_slot_cap_at_128`.

Beyond the new file:
- `Cargo.toml` `[dev-dependencies]` gains `proptest = "1"` and `tracing-subscriber = { workspace = true }` (D-07 dev-only isolation).
- `lib.rs` declares `pub mod session_queue;`. Per D-15 the raw type is NOT publicly re-exported — Plan 02 wires `Arc<SessionQueue>` into `GatewayRunner`.

## Decisions Made

| Decision ID | What | Why |
|---|---|---|
| D-06 | `Mutex<HashMap<SessionKey, VecDeque<MessageEvent>>>` | Single contiguous queue; two-layer Python design ported only as a test mirror |
| D-07 | All parity types in `#[cfg(test)] mod parity` | Zero runtime cost — release build verified to drop the symbols |
| D-08 | Public API uses `try_push/pop/len/clear/retain` | Idiomatic Rust verbs; rustdoc cites Python parity for traceability |
| D-09 | `MAX_QUEUE_DEPTH = 128` per-session | Compartmentalize blast radius; no global cap contention |
| D-10 | Drop-newest on overflow | Causal preservation — the oldest queued event is what the agent acts on next |
| D-11 | `WARN_QUEUE_DEPTH = 96` (75%) via `tracing::warn!` | Operator observability before hard cap |
| D-16 | `std::sync::Mutex` | Gateway crate has no `parking_lot` direct dep; `runner.rs:14` is the prior art |
| D-17 | Sync-only methods | `MutexGuard` is `!Send`; compiler enforces no-await-in-critical-section |
