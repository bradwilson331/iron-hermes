| /new gateway hook → session_store | Mutating both queue and session_store; ordering matters for race-freedom. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-36.17.1-02 | Information Disclosure | synthesized MessageEvent identity inheritance | mitigate | The Queued arm constructs `MessageEvent { content: message.clone(), ..event.clone() }` — platform/chat_id/sender_id/message_id all inherit from the authenticated triggering event.
