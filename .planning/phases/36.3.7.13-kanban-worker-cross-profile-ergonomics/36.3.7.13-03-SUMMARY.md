# Phase 36.3.7.13 Plan 03: Goal-Mode Toolset Filter + Inner-Loop Clamp Summary

Schema v3 migration, toolset filtering (restricted/extended/full presets), inner-loop clamp, and end-to-end wiring from dispatcher env emission to worker-side enforcement — closing F-03 (goal-mode toolset thrash) on both axes.

## What Was Built

### Schema v3 (Task 1)
- Added `goal_toolset TEXT NULL` column to `tasks` table via idempotent v2->v3 migration block
- `SCHEMA_VERSION` bumped from 2 to 3 in schema.rs
- `Task` struct gains `goal_toolset: Option<String>` field
- All 6 `row_to_task` SELECT queries updated to include the column
- 4 bilateral migration tests: idempotency, NULL default, round-trip persistence, fresh-DB presence

### Dispatcher Wiring (Task 2)
- `KanbanConfig` gains `goal_inner_max_iterations: u32` with serde default of 10
- `worker_spawn.rs` emits `HERMES_KANBAN_GOAL_TOOLSET=<preset>` when `goal_mode=true`, coercing NULL->restricted (D-E1)
- `KanbanCreateTool` JSON schema gains optional `goal_toolset` enum field with 3 values
- CLI `--goal-toolset` flag: `Option<String>` + `requires = "goal"`, no `default_value`
- 4 bilateral dispatch tests cover toolset_requires_goal, toolset_accepted_with_goal, default-to-none, valid-command

### Worker-Side Enforcement (Task 3)
- `ToolRegistry::retain_by_name(allowed: &[&str]) -> usize` added as named sibling to `unregister_by_prefix`
- `GOAL_TOOLSET_RESTRICTED`: 13 kanban_* + read_file + write_file (15 tools total)
- `GOAL_TOOLSET_EXTENDED`: restricted + memory + skills + skill_manage (18 tools total)
- `filter_for_goal_mode_if_applicable` async fn:
  - Gate 1: HERMES_KANBAN_TASK must be set (worker mode)
  - Gate 2: HERMES_KANBAN_GOAL_MODE must be "1" (goal mode)
  - D-E2: if HERMES_KANBAN_GOAL_TOOLSET unset -> `tracing::warn!(target: "kanban.goal_toolset", ...)` + early-return (no silent fallback)
  - "full" -> no-op; "extended" -> retain EXTENDED set; other -> retain RESTRICTED set
- `clamp_goal_inner_iterations(config_iter: usize, kanban_iter: u32) -> usize` pure `std::cmp::min` helper
- Both wired at `run_single` and `run_chat` call sites; clamp applied BEFORE `AgentRuntime::from_config`
- 6 bilateral filter tests: restricted exact count (15), extended exact count (18), full no-op, gate-no-task, gate-no-goal-mode, clamp bounds (min(50,10)==10)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] D-E1 initial implementation only emitted env var when goal_toolset was Some**
- **Found during:** Task 3 implementation review
- **Issue:** First Task 2 commit used `if let Some(ref toolset)` in worker_spawn which only emitted HERMES_KANBAN_GOAL_TOOLSET when the field was non-NULL. D-E1 requires dispatcher to coerce NULL->restricted and always emit.
- **Fix:** Changed to `let toolset_preset = task.goal_toolset.as_deref().unwrap_or("restricted"); env.push(...)` inside the goal_mode block, always emitting when goal_mode=true.
- **Files modified:** `crates/ironhermes-kanban/src/worker_spawn.rs`
- **Commit:** `43467c50`

**2. [Rule 1 - Bug] E0716 temporary value dropped while borrowed in goal_toolset_filter.rs**
- **Found during:** Task 3 — cargo test compilation
- **Issue:** `let names = registry.read().await.list_tools()` dropped the read guard before the borrow resolved, causing lifetime errors on three test cases.
- **Fix:** Split into `let guard = registry.read().await; let names = guard.list_tools();` to keep guard alive.
- **Files modified:** `crates/ironhermes-cli/tests/goal_toolset_filter.rs`
- **Commit:** `43467c50`

**3. [Rule 2 - Placement] Inner-loop clamp applied before AgentRuntime::from_config rather than after register_kanban_tools**
- **Found during:** Task 3 — reviewing main.rs to find clamp insertion point
- **Issue:** Plan said "apply after register_kanban_tools_if_applicable" but `AgentRuntime::from_config` captures `config.clone()` at construction time — clamp after runtime construction would have no effect.
- **Fix:** Applied clamp BEFORE `AgentRuntime::from_config` in both `run_single` and `run_chat`. Filter (which needs the registry) is still called after `register_kanban_tools_if_applicable` as specified.
- **Files modified:** `crates/ironhermes-cli/src/main.rs`
- **Commit:** `43467c50`
