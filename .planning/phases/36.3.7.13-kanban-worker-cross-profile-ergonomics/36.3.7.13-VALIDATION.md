| Property | Value |

## Sampling Rate

- **After every task commit:** Run `cargo test -p ironhermes-kanban --no-fail-fast` (or `-p ironhermes-cli` if the touched crate)
- **After every plan wave:** Run `cargo test --workspace --no-fail-fast`
- **Before `/gsd:verify-work`:** Full suite green (modulo the 7 documented pre-existing failures carried forward from Phase 36.3.7.12)
- **Max feedback latency:** ~30 seconds for per-crate, ~120 seconds for workspace
