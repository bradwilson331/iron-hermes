# Phase 36.3.7.9 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Source-of-truth for validation requirements lives in `36.3.7.9-RESEARCH.md` § "Validation Architecture". This file maps each requirement to a concrete test command + sampling cadence the executor must honour.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `cargo test` (Rust 2021) + `tokio::test` for async |
| **Config file** | `Cargo.toml` per crate (no separate test config) |
| **Quick run command** | `cargo test -p ironhermes-kanban --lib` |
| **Crate-scoped CLI command** | `cargo test -p ironhermes-cli --lib --test '*'` |
| **Full suite command** | `cargo test --workspace --all-features` |
| **Estimated quick runtime** | ~30s (kanban crate only) |
| **Estimated full runtime** | ~90-180s (full workspace) |
| **Lint command** | `cargo clippy --workspace --all-targets -- -D warnings` |

---

## Sampling Rate

- **After every task commit:** Run `cargo test -p ironhermes-kanban --lib` (quick run)
- **After every plan wave:** Run `cargo test --workspace` (full suite)
- **Before `/gsd:verify-work`:** Full suite + `cargo clippy --workspace -- -D warnings` must be green
- **Max feedback latency:** 30s for quick run, 180s for full suite

## Wave 0 Requirements

Wave 0 tasks must scaffold test infrastructure for the eight validation surfaces listed in RESEARCH.md § Validation Architecture. The planner is expected to inject Wave 0 entries that create at minimum:

- [ ] `crates/ironhermes-kanban/src/board_context.rs` — unit tests for `resolve_board_context()` (4-tier precedence, 3 chained-fallback scenarios)
- [ ] `crates/ironhermes-kanban/src/slug.rs` — positive/negative `validate_board_slug` tests (lowercase alnum, dashes, underscores, 1 char, 64 chars, leading digit; reject uppercase passthrough → downcase, slashes, `..`, spaces, dots, control chars, 65 chars, empty)
- [ ] `crates/ironhermes-kanban/src/paths.rs` — unit tests for new path helpers (`board_dir`, `board_db_path`, `current_board_file`, `notifier_config_path`, `archive_dir`)
- [ ] `crates/ironhermes-kanban/tests/boards_lifecycle.rs` — integration tests for `boards create / switch / show / rename / rm` archive + hard-delete refusal
- [ ] `crates/ironhermes-kanban/src/notifier_config.rs` — unit tests for `notifier.toml` parser (`["*"]` glob, explicit list, missing file default)
- [ ] `crates/ironhermes-kanban/tests/migration_banner.rs` — integration test asserting stderr banner format on auto-migrate

*If the planner finds existing infrastructure covers a row above, it should mark it ✅ W0 and skip injection.*
