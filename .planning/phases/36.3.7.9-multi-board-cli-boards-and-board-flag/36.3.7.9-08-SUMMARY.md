## Routing Proof

`/kanban boards list` flows through `cmd_kanban` as:
- `args = ["boards", "list"]`
- `args.first() == Some("boards")`
- `DEFERRED_KANBAN_SUBVERBS.contains(&"boards")` → `true`
- Returns `CommandResult::Output(store.deferred_subverb_message("boards"))`
- Output: `/kanban boards: use 'hermes kanban boards' from the CLI for this subverb.`

The downstream `list` token is not consumed; the same message is returned whether the user typed `/kanban boards` or `/kanban boards list` or `/kanban boards rm <slug>`.
