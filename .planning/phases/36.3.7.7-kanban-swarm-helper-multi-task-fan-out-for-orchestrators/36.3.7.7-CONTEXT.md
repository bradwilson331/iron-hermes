**Status:** STUB — placeholder so the phase has a home on disk. No planning artifacts yet.

## Goal (verbatim from ROADMAP)

Ship `kanban swarm` as both a CLI verb (`hermes kanban swarm`) and an LLM tool
(`kanban_swarm`) — a multi-task fan-out helper for orchestrators that creates
N child tasks from a single dispatch with shared metadata (assignee defaulting
per task, shared parent, shared skills set, shared workspace). Currently
referenced at `docs/kanban/reference.md` §664 as deferred. Use case: an
orchestrator processes a backlog of similar items (10 PRs to review, 50 docs
to ingest, 20 tasks to triage) and wants atomic batch-create instead of N
individual `kanban_create` calls. Includes idempotency key support (per-child
suffix) and a single-transaction insert path through `KanbanStore`. Stretches
the existing 9-tool surface to 10 LLM tools / matching CLI surface.
