### `crates/ironhermes-kanban/src/store.rs` (MODIFY — add `create_swarm` + new types)

**Analog:** `crates/ironhermes-kanban/src/store.rs:440-481` (`insert_link_checked`)

**Pattern to mirror:** Open a `BEGIN IMMEDIATE` transaction via `self.conn.transaction_with_behavior(TransactionBehavior::Immediate)`, run all reads and writes via `tx.execute(...)` / `tx.query_row(...)`, pass `&tx` (not `&self.conn`) to `append_event_internal`, call `tx.commit()` at the end. Idempotency short-circuit mirrors `create_task:219-223` — look up root by `"k:root"` key before opening the transaction.

```rust

    conn: &Connection,
    task_id: &str,
    run_id: Option<&str>,
    kind: KanbanEventKind,
    payload: Option<&Value>,
    now: f64,
) -> Result<i64> {
    let payload_str = payload.map(|v| v.to_string());
    conn.execute(
        "INSERT INTO task_events (task_id, run_id, kind, payload, created_at) \
         VALUES (?1, ?2, ?3, ?4, ?5)",
        params![task_id, run_id, kind.as_str(), payload_str, now],
    )?;
    Ok(conn.last_insert_rowid())
}
```

**Idempotency short-circuit** (store.rs:218-223):

For `create_swarm`: look up `"k:root"` before opening the tx; if found, walk `task_links` to reconstruct `SwarmGraphIds`.

**New types placement:** `SwarmGraphSpec`, `SwarmGraphIds`, `KanbanWorkerSpec` belong in `store.rs` alongside `CreateTaskOptions` (line 31). `CreateTaskOptions` lives there as a public struct; `SwarmGraphSpec` follows the same idiom. All three must be `pub`.
