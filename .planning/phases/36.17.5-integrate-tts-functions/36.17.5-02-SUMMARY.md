## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Task 1 placeholder stubs required TtsProvider impl to compile**
- **Found during:** Task 1 build verification
- **Issue:** `build_tts_registry()` in `mod.rs` calls `Arc::new(EdgeProvider::new(...))` and `Arc::new(ElevenLabsProvider::new(...))` which requires those types to implement `TtsProvider`. Placeholder structs without impls caused `E0277`.
- **Fix:** Added stub `TtsProvider` impls to both placeholder files so Task 1 compiles. Task 2/3 replaced these with real implementations.
- **Files modified:** `tts/edge.rs`, `tts/elevenlabs.rs`
- **Commit:** 569a81ee

**2. [Rule 1 - Bug] Rust 2024 edition requires unsafe blocks for env mutations**
- **Found during:** Task 2 test compilation
- **Issue:** `std::env::set_var` and `std::env::remove_var` are `unsafe` in Rust 2024 edition (workspace uses `edition = "2024"`). Test file `E0133` compilation errors.
- **Fix:** Wrapped all `set_var`/`remove_var` calls in `unsafe {}` blocks with SAFETY comments explaining the serialization via `env_lock()`.
- **Files modified:** `tests/tts_tools.rs`
- **Commit:** 85d38bc4

**3. [Note] TTS-04 un-ignored in Task 2 (not Task 3 as planned)**
- **Found during:** Task 2 test file rewrite
- **Issue:** PLAN 02 specified TTS-04 to be un-ignored in Task 3, but the ElevenLabsProvider's `is_available()` was already correctly implemented in the Task 1 stub. Un-ignoring it during the Task 2 test rewrite was strictly correct.
- **Impact:** #[ignore] count after Task 2 was 3 (not 4 as plan expected). After Task 3 it remains 3. All tests pass. No behavioral deviation.
- **Commit:** 85d38bc4
