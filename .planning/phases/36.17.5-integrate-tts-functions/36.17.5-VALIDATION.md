## UAT Script Specification

**File:** `scripts/uat/phase-36.17.5-tts.sh`
**Model:** `scripts/uat/phase-36.17-web-logging.sh` (bash strict mode, gate-echo pattern, `GATE FAIL` diagnostics)
**Isolation:** `mktemp -d` temp `IRONHERMES_HOME`; trap-cleanup on exit; no Telegram bot token required (Edge TTS is keyless).

**Gates:**

1. **Gate 1 (D-03 / D-16):** After CLI TTS trigger, `$IRONHERMES_HOME/audio_cache/` exists and contains exactly one UUID-named `.mp3` file.
2. **Gate 2 (D-04 / D-05 / D-03):** Synthesized file is non-empty (Edge TTS returned real audio bytes).
3. **Gate 3 (D-10):** `ironhermes` binary exits 0 when `tts.provider = "edge"` — no API key panic, no `unimplemented!` panic.
4. **Gate 4 (registry / D-08):** Both `text_to_speech` and `send_audio` appear in the tool list (registry pickup confirmation).
5. **Gate 5 (D-15 / Platform::Local):** `send_audio` with `Platform::Local` either plays audibly or returns a clear error (NOT a panic).
