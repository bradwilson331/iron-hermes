## Schema Change (Verbatim Inserted DDL)

In `crates/ironhermes-kanban/src/schema.rs::SCHEMA_SQL`, inserted between
`task_runs` (existing last table) and the `-- Indexes` separator:

```sql
-- -----------------------------------------------------------------------
-- kanban_subscriptions  (Phase 36.3.7.5 BUG-36.3.7.5-01 — gateway notifier subscriptions)
-- -----------------------------------------------------------------------
-- One row per (task, chat-origin) pair. Auto-subscriptions from /kanban create
-- have source='auto'; explicit notify-subscribe verbs have source='explicit'.
-- thread_id defaults to '' (NOT NULL) so the UNIQUE constraint covers thread-less
-- chats (SQLite UNIQUE treats NULL as distinct, which would break our key).
CREATE TABLE IF NOT EXISTS kanban_subscriptions (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id     TEXT NOT NULL,
    platform    TEXT NOT NULL,
    chat_id     TEXT NOT NULL,
    thread_id   TEXT NOT NULL DEFAULT '',
    source      TEXT NOT NULL CHECK (source IN ('auto', 'explicit')),
    created_at  REAL NOT NULL,
    UNIQUE (task_id, platform, chat_id, thread_id)
);
```

And inserted at the end of the existing index block, after the 4 existing indexes:

```sql
CREATE INDEX IF NOT EXISTS idx_subs_task_id
    ON kanban_subscriptions(task_id);

CREATE INDEX IF NOT EXISTS idx_subs_chat
    ON kanban_subscriptions(platform, chat_id, thread_id);
```

The 2 indexes support the two production query patterns:
- `list_subscriptions_for_task(task_id)` — notifier delivery path (Plan 02).
- `list_subscriptions_for_chat(platform, chat_id, thread_id)` — CLI `notify-list --chat` + `notify-unsubscribe` (Plan 04).

`SCHEMA_VERSION` stayed at `1`; `run_migrations` stayed empty. `CREATE TABLE IF NOT
EXISTS` makes the new table a no-op on every re-open — no version bump required.

## Subscription Struct

Appended to `crates/ironhermes-kanban/src/types.rs` after `TaskComment` (struct
ordering preserved consistency with the existing 4 structs) and re-exported from
`crates/ironhermes-kanban/src/lib.rs`:

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Subscription {
    pub id: i64,
    pub task_id: String,
    pub platform: String,
    pub chat_id: String,
    pub thread_id: String,  // '' = no thread; NOT Option<String> — see schema CHECK
    pub source: String,     // "auto" | "explicit" — enforced by CHECK
    pub created_at: f64,
}
```

Boundary types match `Task` / `TaskComment` / `TaskLink` / `TaskRun` (D-17): plain
`String` + numeric primitives, no enum at the crate boundary.
