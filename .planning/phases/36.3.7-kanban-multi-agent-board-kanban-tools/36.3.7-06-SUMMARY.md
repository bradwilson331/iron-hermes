## What Was Built

### Task 1: Kanban CLI module

Three new files under `crates/ironhermes-cli/src/kanban/`:

- **`mod.rs`**: `KanbanCommands` enum (24 variants via `#[derive(Subcommand)]`) and `handle_kanban_command` dispatcher routing each variant to a `commands::cmd_*` function.
- **`commands.rs`**: Per-verb async implementations for all 24 D-33 verbs: `init`, `create`, `list`, `show`, `assign`, `link`, `unlink`, `claim`, `comment`, `complete`, `block`, `unblock`, `archive`, `tail`, `watch`, `runs`, `assignees`, `dispatch`, `stats`, `log`, `context`, `gc`, `reclaim`, `reassign`, `diagnostics`, `daemon`. D-34 bulk-summary refusal in `cmd_complete` exits with code 2 when `ids.len() > 1` and `--summary`/`--metadata` are passed.
- **`format.rs`**: Pure formatting helpers: `format_task_table`, `format_task_json`, `format_task_detail`, `format_runs_table`, `format_diagnostics`, `format_stats`, `format_assignees`, `format_event_line`.

`crates/ironhermes-cli/src/main.rs` gains `mod kanban;`, `Commands::Kanban { command: kanban::KanbanCommands }` variant, and the dispatch arm.

### Auto-fixed Issues

**1. [Rule 1 - Bug] `StrandedReport.stranded_seconds` field does not exist**
- **Found during:** Task 1 (format.rs)
- **Issue:** Plan referenced `stranded_seconds` but the struct uses `age_seconds: f64`
- **Fix:** Used `age_seconds` throughout `format_diagnostics`
- **Files modified:** crates/ironhermes-cli/src/kanban/format.rs
- **Commit:** f585b4fb

**2. [Rule 2 - Missing] `KanbanStore::get_comments` not exposed publicly**
- **Found during:** Task 1 (commands.rs `cmd_show`)
- **Issue:** `cmd_show` needs task comments but `KanbanStore` has no public `get_comments` method
- **Fix:** Inline `get_comments()` helper using `store.conn.prepare()` directly (store.rs out of scope per wave_context)
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** f585b4fb

**3. [Rule 2 - Missing] `KanbanStore::delete_link` not exposed publicly**
- **Found during:** Task 1 (commands.rs `cmd_unlink`)
- **Issue:** `cmd_unlink` needs to delete a link row but no public method exists
- **Fix:** Inline `delete_link()` helper using `store.conn.execute()` directly
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** f585b4fb

**4. [Rule 1 - Bug] `run_dispatch_tick` returns `Result<()>` not a stats struct**
- **Found during:** Task 1 (commands.rs `cmd_dispatch`)
- **Issue:** Initial implementation tried to access `.claimed` / `.spawned` fields on the return value
- **Fix:** `cmd_dispatch` calls `run_dispatch_tick(&ctx).await?` and reports completion without field access
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** f585b4fb

**5. [Rule 1 - Bug] E0506 borrow conflict in `cmd_tail`/`cmd_watch`**
- **Found during:** Task 1 (commands.rs)
- **Issue:** `filter(|e| e.id > last_id)` borrows `last_id` immutably while the loop body assigns to it
- **Fix:** Collect events into `Vec`, then iterate — eliminates the overlapping borrow
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** f585b4fb
