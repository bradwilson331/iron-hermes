### Task 2: Dispatcher Tick Loop (GREEN)

**`dispatcher.rs` (new, ~500 LOC):**

```
DispatcherContext { store, config, hostname, dispatcher_pid, spawn_fn }
  ├── new(store, config) — uses real spawn_worker
  └── with_spawn_fn(store, config, spawn_fn) — injectable for tests

run_dispatch_loop(ctx, CancellationToken) — tokio select! interval loop
run_dispatch_tick(ctx) — 8 D-10 steps in sequence:
  1. detect_crashed_workers   — running tasks with dead PID → reclaim
  2. extend_live_pid_claims   — running tasks with alive PID + near-expired claim → extend
  3. reclaim_stale_claims     — running tasks with expired claim (PID unknown) → reclaim
  4. enforce_max_runtime      — tasks exceeding max_runtime_seconds → SIGTERM→grace→SIGKILL
  5. promote_ready            — todo tasks whose all parents are done → ready
  6. claim_and_spawn          — ready tasks (respawn guard check, max_in_progress cap) → claim + spawn
  7. respawn_guard_reason     — blocker_auth (429/auth error) / recent_success (<3600s) / active_pr (GitHub PR URL in comment)
  8. apply_circuit_breaker    — consecutive_failures >= failure_limit → gave_up event + block_task

diagnose_stranded(store, threshold_secs) — D-14 severity bands:
  Warn: age > 1× threshold
  Error: age > 2× threshold
  Critical: age > 6× threshold
```

**`tests/dispatcher_logic.rs` (new, 10 integration tests):**
- All 8 D-10 steps covered
- Injectable spawn_fn via `DispatcherContext::with_spawn_fn`
- State seeded via `store.conn` (after making `conn` pub)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `nix::unistd::gethostname` not available**
- **Found during:** Task 1 implementation
- **Issue:** Workspace `nix` dep only has `features = ["process"]`; kanban adds `["signal"]` but not `["hostname"]`. `gethostname()` is gated behind the `hostname` feature.
- **Fix:** Replaced with pure approach: check `HOSTNAME` env var → read `/etc/hostname` → fallback `"unknown"`. No feature flag required, works in all target environments.
- **Files modified:** `pid.rs`
- **Commit:** e7704605

**2. [Rule 1 - Bug] `store.conn` inaccessible from integration tests**
- **Found during:** Task 2 test GREEN phase
- **Issue:** `conn` was `pub(crate)` — integration tests in `tests/` are a separate crate and cannot access `pub(crate)` fields.
- **Fix:** Promoted `conn` to `pub` with a doc comment explaining the rationale (test state seeding, not for production use). This is an internal crate so the pub surface stays within the workspace.
- **Files modified:** `store.rs`
- **Commit:** 34bbef3b

**3. [Rule 1 - Bug] Unused import `build_kanban_worker_env` in dispatcher.rs**
- **Found during:** Task 1 compilation
- **Issue:** Dispatcher calls `spawn_fn` which internally calls `spawn_worker` (which calls `build_kanban_worker_env`). Direct import was unused.
- **Fix:** Removed the direct import.
- **Commit:** e7704605
