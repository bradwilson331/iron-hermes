<objective>
Close BUG-36.3.7.1-01 by wiring `apply_circuit_breaker` into the `reclaim_stale_claims` path
in `crates/ironhermes-kanban/src/dispatcher.rs`. The path currently bumps
`consecutive_failures` (lines 462-469) but never invokes the breaker — same structural shape
as the BUG-36.3.7-03 gap that 36.3.7.0-03 closed on `detect_crashed_workers`. Plus partially
land BUG-36.3.7.1-03 by adding the two receiver-end tests that cover both sides of the
`failure_limit` bound on this path.

Purpose: make the `failure_limit` config knob behave per operator intuition on the
claim-TTL-expired path. A task whose worker died without notifying the dispatcher (PID dead
or null, claim TTL expired) should be blocked on the SAME tick that bumps `consecutive_failures`
to the limit, not one tick later via the spawn-failure breaker.

Output: a single ~6 LOC insertion in `reclaim_stale_claims` + a 4-line inline comment marker
+ 2 new `#[tokio::test]` functions in `tests/dispatcher_logic.rs`.
