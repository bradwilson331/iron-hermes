## Critical Anti-Patterns (do NOT repeat these)

- **ANTI-PATTERN: Spawning executor with background cargo build** → executor self-loops on stale JoinHandle notifications; must use foreground `cargo check` / `cargo test` with explicit timeout.
- **ANTI-PATTERN: Removing the explicit `.unwrap()` from `session_key: Some(...).unwrap()` literal** → breaks the D-05 source-grep invariant in invariants_36_17_7.rs. The redundant Some/unwrap pair is load-bearing as a regex anchor.
- **ANTI-PATTERN: Adding new `Platform::Foo` arms to send_audio_tool.rs without a corresponding `AudioDispatcher` impl** → reproduces the UAT-W bug. Every new platform must ship dispatcher + tool arm together.
