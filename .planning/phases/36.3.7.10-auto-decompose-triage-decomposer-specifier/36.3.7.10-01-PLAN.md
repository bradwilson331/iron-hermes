## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Config file → KanbanConfig | Operator-supplied YAML enters via serde — every new field has a serde default so unknown / omitted fields don't fail the load |
| Slash-arg dispatcher → DEFERRED_KANBAN_SUBVERBS | Untrusted slash-arg name is matched against a static allowlist before producing the deferred response — no execution path |
| Config file → validate_role_name | Operator-supplied role-name string is checked against `RESERVED_ROLE_NAMES` membership; unknown names are rejected at config load |
