## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] ProviderResolver is the correct type name (not ProviderRegistry)**
- **Found during:** Task 1 build
- **Issue:** Plan referred to `ProviderRegistry::from_config` but the actual type in `ironhermes-core/src/provider.rs` is `ProviderResolver` with constructor `build(config)`.
- **Fix:** Used `ProviderResolver::build(main_config)` with the correct import path.
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** c85a0684

**2. [Rule 1 - Bug] MessageContent::as_text() required for response extraction**
- **Found during:** Task 1 build
- **Issue:** `ChatResponse.choices[0].message.content` is `Option<MessageContent>` not `Option<String>`, so `as_deref()` does not compile.
- **Fix:** Used `.and_then(|mc| mc.as_text())` which calls `MessageContent::as_text()` (returns `Option<&str>`).
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** c85a0684

**3. [Rule 1 - Bug] KanbanStore has no config field**
- **Found during:** Task 1 implementation
- **Issue:** Plan's CR-WARNING-5 sourcing seam says to add `pub fn config(&self) -> &KanbanConfig { &self.config }` but `KanbanStore` only stores `conn: Connection` — no `config` field. The per-board config.yaml is not loaded at `open()` time.
- **Fix:** Added `pub fn config(&self) -> crate::config::KanbanConfig { crate::config::KanbanConfig::default() }` returning a default. Main KanbanConfig loaded separately in cmd_ fns via `Config::load() + load_kanban_config()` deserialization of `config.kanban: serde_yaml::Value`.
- **Files modified:** crates/ironhermes-kanban/src/store.rs
- **Commit:** c85a0684

**4. [Rule 1 - Bug] KanbanError::Other wraps anyhow::Error (not String)**
- **Found during:** Task 1 build
- **Issue:** `ironhermes_kanban::error::Error::Other` does not exist; the correct path is `ironhermes_kanban::KanbanError::Other` which wraps `anyhow::Error` (via `#[from]`), not a raw `String`.
- **Fix:** Used `ironhermes_kanban::KanbanError::Other(anyhow::anyhow!("{}", e))` in the closure's error paths.
- **Files modified:** crates/ironhermes-cli/src/kanban/commands.rs
- **Commit:** c85a0684
