## Deviations from Plan

### Auto-fixed Issues

None beyond the minor items below.

**1. [Rule 1 - Bug] Removed updated_at from UPDATE statements**
- **Found during:** Task 1 build
- **Issue:** Initial `apply_specify` and `apply_decompose` included `updated_at = ?` in the UPDATE SQL, but `tasks` schema has no `updated_at` column.
- **Fix:** Removed `updated_at` from both SQL statements. Standard rusqlite `params!` bindings confirmed no `format!` interpolation.
- **Files modified:** crates/ironhermes-kanban/src/store.rs
- **Commit:** 4566eccd (fixed before commit)

**2. [Rule 2 - Missing field] Added created_at to list_links_for_parent row mapping**
- **Found during:** Task 1 build
- **Issue:** `TaskLink` struct has `created_at: f64` field, but initial SELECT only fetched `parent_id, child_id`.
- **Fix:** Updated SELECT to `SELECT parent_id, child_id, created_at` and mapped the field.
- **Files modified:** crates/ironhermes-kanban/src/store.rs
- **Commit:** 4566eccd (fixed before commit)
